Create N instances.

Detailed Explanation

Creates multiple instances of a resource. Accessed via count.index.

meta-arguments

count meta-argument?

Quick Answer

Looping resource creation.

Detailed Explanation

Allows creating multiple instances of a resource based on a count integer. Resources are indexed (e.g., instance[0]).

Code Example
count = 3
lifecycle

create_before_destroy?

Quick Answer

Zero downtime replacement.

Detailed Explanation

Lifecycle argument that forces Terraform to create the new resource first, and then destroy the old one, rather than the default destroy-then-create.

Code Example
lifecycle { create_before_destroy = true }

meta

for_each meta-argument?

Quick Answer

Loop over map/set.

Detailed Explanation

Creates resource for each item. Preferred over count because removing an item doesn't shift indices.

Code Example
for_each = var.buckets
meta-arguments

for_each meta-argument?

Quick Answer

Looping over map/set.

Detailed Explanation

Similar to count, but iterates over a map or set of strings. Resources are identified by the map key, which is safer than index if list order changes.

Code Example
for_each = toset(["a", "b"])

Force recreate.

State Locking?

Quick Answer

Prevent concurrent writes.

Detailed Explanation

Feature of backends (like S3 + DynamoDB) to lock the state file during operations. Prevents two people from running apply at the same time and corrupting state.

modules

What is a Module?

Quick Answer

Reusable configuration.

Detailed Explanation

A container for multiple resources that are used together. Every Terraform configuration has at least one module (root module). Used for DRY (Don't Repeat Yourself).

Code Example
module "servers" { source = "./app-cluster" }
