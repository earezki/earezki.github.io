LifecycleEffect

useLayoutEffect vs useEffect?

Quick Answer

useLayoutEffect fires synchronously after all DOM mutations. useEffect fires asynchronously.

Detailed Explanation

Use useLayoutEffect if you need to read the DOM and re-render synchronously (prevents visual flicker). Use useEffect for 99% of cases (data fetching) to avoid blocking the visual update.

useMemo vs useCallback?

Quick Answer

Value vs Function.

Detailed Explanation
  • useMemo: Memoizes a value (result of function). Re-computes only when deps change.
  • useCallback: Memoizes a function definition. Re-creates only when deps change.
Code Example
useMemo(() => complexCalc(a), [a])
useCallback(() => doClick(a), [a])
OptimizationHooks

useMemo vs useCallback?

Quick Answer

useMemo memoizes a value (result of evaluation). useCallback memoizes a function definition.

Detailed Explanation

Use useMemo for expensive calculations. Use useCallback to prevent function recreation on every render, which is important when passing functions as props to memoized child components (React.memo).

Code Example

const val = useMemo(() => heavy(a), [a]);

What is the difference between Controlled and Uncontrolled components?

Quick Answer

Controlled components have their state managed by React; Uncontrolled components maintain their own internal state.

Detailed Explanation

In a controlled component, form data is handled by a React component (via useState and onChange). In an uncontrolled component, form data is handled by the DOM itself (accessed via useRef). Controlled components are generally recommended.

When does useEffect cleanup run?

Quick Answer

When the component unmounts and before the effect runs again.

Detailed Explanation

If you return a function from useEffect, React will call it when the component unmounts to clean up (like removing event listeners). If dependencies change, it also runs cleanup from the previous render before running the effect again.

Code Example
useEffect(() => {
  const id = setInterval(tick, 1000);
  return () => clearInterval(id);
}, []);
