Quick Answer

Controlled: Form input values controlled by React state. Uncontrolled: Form values handled by the DOM itself (using refs).

What are the two main types of components in React?

Quick Answer

Class Components and Functional Components.

Detailed Explanation

Class components are ES6 classes that extend React.Component and have a render method. Functional components are simple JavaScript functions that return JSX. Functional components are now preferred with the introduction of Hooks.

  render() { return <h1>Hello</h1>; }
}
