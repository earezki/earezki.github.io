Quick Answer

React 18 batches state updates triggered from promises, timeouts, and native event handlers.

Detailed Explanation

Explain Event Delegation in React.

Quick Answer

React attaches one single event listener to the root of the document (or root container in v17) rather than to every node.

Detailed Explanation

When an event occurs, it bubbles up to the root. React's internal event system maps that target element back to the component instance and invokes the correct handler. This saves memory.

How does React's Reconciliation Key algorithm work?

Quick Answer

It compares the root elements and recurses on children.

Detailed Explanation

When comparing two pseudo-DOM trees, React first compares the two root elements. If they act as different types, React tears down the old tree and builds a new one. When comparing children lists, it uses keys to match children in the original tree with children in the subsequent tree to minimize DOM operations.

Code Example
<div>...</div> vs <span>...</span> -> Full Rebuild

What are Error Boundaries?

Quick Answer

React components that catch JavaScript errors anywhere in their child component tree.

Detailed Explanation

Error boundaries catch errors during rendering, in lifecycle methods, and in constructors of the whole tree below them. They define static getDerivedStateFromError() or componentDidCatch(). Note: They do not catch errors in event handlers.

Code Example
class ErrorBoundary extends React.Component {
  static getDerivedStateFromError(error) {
    return { hasError: true };
  }
  render() { ... }
}

What is useMemo vs useCallback?

Quick Answer

useMemo memoizes a value; useCallback memoizes a function.

Detailed Explanation

useMemo returns a memoized value that only recalculates when dependencies change. useCallback returns a memoized callback function. useCallback(fn, deps) is equivalent to useMemo(() => fn, deps). They are used to optimize performance by preventing unnecessary re-renders or calculations.

Code Example
const memoizedValue = useMemo(() => computeExpensiveValue(a, b), [a, b]);
const memoizedCallback = useCallback(() => {
  doSomething(a, b);
}, [a, b]);

What is the difference between SSR and CSR?

Quick Answer

SSR renders HTML on the server; CSR renders it in the browser.

Detailed Explanation

Server-Side Rendering (SSR) sends fully rendered HTML to the client, improving initial load time and SEO. Client-Side Rendering (CSR) sends a blank HTML page and uses JavaScript to build the UI. Frameworks like Next.js facilitate SSR with React.
