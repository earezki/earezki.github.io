flushSync?

Click to reveal  ·  Space
Quick Answer

Forces a synchronous re-render.

Explanation

Bypasses batching. Use rarely, e.g., when you need to read the DOM immediately after a state change.

Code Example
flushSync(() => setCount(1));
// DOM is updated here
