IORedirection

> vs >>?

Quick Answer

> redirects output overwriting the file. >> redirects output appending to the file.

Detailed Explanation

Both redirect Standard Output (stdout) to a file. To redirect Standard Error (stderr), use 2>.

Code Example

echo "Log" >> file.txt

PermissionsSecurity

chmod command?

Quick Answer

Changes file mode bits (permissions).

Detailed Explanation

Permissions are Read (4), Write (2), Execute (1). chmod 755 file means Owner=7(4+2+1), Group=5(4+1), Others=5(4+1).

Code Example

chmod +x script.sh

VariablesEnv

export command?

Quick Answer

Sets an environment variable to be available to child processes.

Detailed Explanation

Without export, a variable is only local to the current shell. With export, it is copied to the environment of any command run from that shell.

Code Example

export PATH=$PATH:/opt/bin

FilesSearch

grep usage?

Quick Answer

Global Regular Expression Print. Searches for patterns in files.

Detailed Explanation

grep -r "text" . searches recursively in current directory. -i ignores case. -v inverts match (shows lines NOT matching).

Code Example

cat log.txt | grep "ERROR"

CLIFiles

ls command usage?

Quick Answer

Lists directory contents.

Detailed Explanation

Common flags: -l (long format, showing permissions/size), -a (all files including hidden ones starting with .), -h (human readable sizes).

Code Example

ls -lah

FilesManipulation

mv vs cp?

Quick Answer

mv moves (renames) files. cp copies files.

Detailed Explanation

mv is fast on the same filesystem (just updates the inode link). cp duplicates the data blocks.

Code Example

mv old.txt new.txt

NetworkingBasics

ping command?

Quick Answer

Checks connectivity to a host.

Detailed Explanation

Sends ICMP ECHO_REQUEST packets to network hosts. Useful to check if a server is reachable and measure round-trip time (latency).

Code Example

ping google.com

ProcessesMonitoring

ps and top?

Quick Answer

ps shows a snapshot of current processes. top displays real-time system summary.

Detailed Explanation

ps aux looks at all processes for all users. top (or htop) allows sorting by CPU/Memory usage and killing processes interactively.

Code Example

ps aux | grep java

UsersSecurity

sudo command?

Quick Answer

SuperUser DO. Executes a command as another user (usually root).

Detailed Explanation

It allows a permitted user to execute a command as the superuser, as specified by the /etc/sudoers file.

Code Example

sudo apt update

FilesViewing

tail vs head?

Quick Answer

tail outputs the last part of files. head outputs the first part.

Detailed Explanation

tail -f is extremely useful for following log files in real time as they are written.

Code Example

tail -f /var/log/syslog
