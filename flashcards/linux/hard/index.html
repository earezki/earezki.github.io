FilesystemMount

/proc filesystem?

Quick Answer

A pseudo-filesystem (virtual) that provides an interface to kernel data structures.

Detailed Explanation

It doesn't exist on disk. /proc/cpuinfo (CPU info), /proc/meminfo (RAM usage), /proc/[pid] (info about specific process).

Code Example

cat /proc/cpuinfo

PerformanceDisk

iostat usage?

Quick Answer

Reports CPU statistics and input/output statistics for devices and partitions.

Detailed Explanation

Useful to diagnose I/O bottlenecks. Look at '%iowait' (CPU waiting for disk) and 'await' (average time for I/O request to complete).

Code Example

iostat -x 1

NetworkingFirewall

iptables / nftables?

Quick Answer

Standard linux firewall tools to configure kernel packet filtering rules.

Detailed Explanation

Works with chains (INPUT, OUTPUT, FORWARD) and tables. Rules determine if a packet is ACCEPTed, REJECTed, or DROPPed.

Code Example

iptables -A INPUT -p tcp --dport 22 -j ACCEPT

PerformanceTracing

strace command?

Quick Answer

Traces system calls and signals.

Detailed Explanation

Extremely useful for debugging binaries without source code. It shows every file opened, network socket connected, or memory allocated by the program.

Code Example

strace -p 1234

KernelIO

Load Average in uptime?

Quick Answer

The average number of processes in the run queue (CPU) or waiting for disk I/O over the last 1, 5, and 15 minutes.

Detailed Explanation

A load of 1.0 means one CPU core is fully utilized. If Load > Number of Cores, system is overloaded. High load with low CPU usage suggests I/O bottleneck.

Code Example

uptime

SystemSignals

SIGTERM vs SIGKILL?

Quick Answer

SIGTERM (15) politely asks the process to stop (allows cleanup). SIGKILL (9) forces immediate termination (kernel kills, no cleanup).

Detailed Explanation

Always try SIGTERM first. Use SIGKILL only if process is stuck. kill pid sends SIGTERM by default.

Code Example

kill -9 1234

PermissionsAdvanced

Sticky Bit, SUID, SGID?

Quick Answer

Special permission bits.

Detailed Explanation

SUID (4): Run executable with Owner's permissions (e.g., passwd). SGID (2): New files inherit Group of directory. Sticky Bit (1): Only file owner can delete file in directory (e.g., /tmp).

Code Example

chmod +t /tmp

KernelSystem

What is a Zombie Process?

Quick Answer

A process that has completed execution but still has an entry in the process table.

Detailed Explanation

This happens if the parent process hasn't read the child's exit status (via wait() syscall). They consume very few resources (just a PID), but too many can fill the PID table. You cannot kill a zombie; you must kill its parent.

FilesystemInodes

What is an Inode?

Quick Answer

A data structure on a filesystem that stores metadata about a file (size, permissions, owner, location on disk), but NOT the filename.

Detailed Explanation

The filename is stored in the directory entry, pointing to the inode number. You can run out of inodes (df -i) even if you have disk space left (many small files).

Code Example

ls -i file.txt

KernelMemory

What is Swap Space?

Quick Answer

A portion of the hard drive used as extension of RAM.

Detailed Explanation

When RAM is full, the kernel moves inactive pages to Swap (paging out). Accessing Swap is orders of magnitude slower than RAM (thrashing).

Code Example

swapon -s
