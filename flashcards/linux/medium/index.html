awk command?

Click to reveal  ·  Space
Quick Answer

A powerful programming language for data extraction and reporting.

Explanation

It processes files line by line, splitting fields by whitespace (default). Useful for extracting columns from logs/csv.

Code Example

ps aux | awk '{print $1, $2}'
