Are Java strings mutable?

Click to reveal  ·  Space
Quick Answer

No, Java strings are immutable.

Explanation

Java String objects are immutable, meaning their character sequence cannot be changed after creation, with any operation that appears to modify a string actually creating a new String instance. Core functionality includes thread-safe sharing, string interning for memory efficiency, and extensive utility methods like substring(), concat(), and replace(). Key features encompass the string pool (a JVM cache of literal strings) and methods for comparison, searching, and manipulation. Internal architecture uses a char array with an offset and length for efficient substring operations without copying. Recommended practices include using StringBuilder or StringBuffer for multiple concatenations, preferring equals() over == for content comparison, and using string literals for constants. Common mistakes include using == for comparison (compares references, not content), inefficient concatenation in loops, and forgetting that substring() shares the underlying char array in older Java versions. Practical use cases include text processing, configuration keys, and immutable identifiers. Performance implications: immutability enables safe sharing but concatenation creates many temporary objects; StringBuilder is mutable and efficient for building strings incrementally.

Code Example
import java.util.Arrays;

public class StringImmutabilityDemo {
    public static void main(String[] args) {
        // String literals are interned (shared)
        String s1 = "Hello";
        String s2 = "Hello";
        System.out.println("s1 == s2: " + (s1 == s2)); // true (same reference)
        System.out.println("s1.equals(s2): " + s1.equals(s2)); // true (same content)
        
        // Creating new strings
        String s3 = new String("Hello"); // Not interned
        System.out.println("s1 == s3: " + (s1 == s3)); // false (different references)
        
        // Immutability demonstration
        String original = "Hello";
        String modified = original.concat(" World"); // Creates new string
        System.out.println("Original: " + original); // Still "Hello"
        System.out.println("Modified: " + modified); // "Hello World"
        
        // Inefficient concatenation (creates multiple objects)
        String result = "";
        for (int i = 0; i < 5; i++) {
            result += i + " "; // Creates new string each time
        }
        System.out.println("Inefficient result: " + result);
        
        // Efficient concatenation using StringBuilder
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < 5; i++) {
            sb.append(i).append(" "); // Modifies same object
        }
        String efficientResult = sb.toString();
        System.out.println("Efficient result: " + efficientResult);
        
        // String methods with error handling
        String text = "  Hello World  ";
        try {
            String trimmed = text.trim(); // Remove whitespace
            String upper = trimmed.toUpperCase(); // Convert to uppercase
            String substring = upper.substring(0, 5); // Extract first 5 chars
            System.out.println("Processed: '" + substring + "'");
            
            // Safe substring with bounds checking
            int startIndex = 6;
            int length = 5;
            if (startIndex >= 0 && startIndex + length <= upper.length()) {
                String safeSubstring = upper.substring(startIndex, startIndex + length);
                System.out.println("Safe substring: '" + safeSubstring + "'");
            } else {
                System.out.println("Invalid substring indices");
            }
            
        } catch (StringIndexOutOfBoundsException e) {
            System.out.println("String operation error: " + e.getMessage());
        }
        
        // String comparison examples
        String str1 = "apple";
        String str2 = "Apple";
        System.out.println("Case-sensitive equals: " + str1.equals(str2)); // false
        System.out.println("Case-insensitive equals: " + str1.equalsIgnoreCase(str2)); // true
        
        // Splitting strings
        String csv = "name,age,city";
        String[] parts = csv.split(",");
        System.out.println("Split result: " + Arrays.toString(parts));
    }
}
