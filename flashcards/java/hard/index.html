ConcurrentHashMap internals (Java 8+)?

Click to reveal  ·  Space
Quick Answer

Does not use global lock (segmentation). Uses CAS and synchronized on the head node of the bucket.

Explanation

Reads are lock-free. Writes only lock the specific bucket being modified. Resizing is performed concurrently by multiple threads helping to transfer nodes.
