ArchitectureEvent Loop

Blocking vs Non-Blocking code?

Quick Answer

Blocking code executes synchronously (halts execution). Non-Blocking executes asynchronously (continues execution).

Detailed Explanation

Node.js uses a single thread. Blocking that thread (CPU heavy tasks, or Sync I/O) stops the entire server for all clients. Always prefer Non-Blocking (Async) I/O.

Code Example

const data = fs.readFileSync('file'); // Blocking

Explain 'Middleware' pattern (Express).

Quick Answer

Functions that have access to the request object (req), the response object (res), and the next middleware function (next).

Detailed Explanation

They can execute code, modify req/res, test conditions, or end the request. The order of declaration matters. If next() is not called, the request hangs.
