__dirname and __filename?

Quick Answer

__dirname is the directory name of the current module. __filename is the file name of the current module.

Detailed Explanation

They are local variables in every module (wrapper), providing absolute paths. They are not global objects but look like them.

Code Example

console.log(__dirname);

module.exports vs exports?

Quick Answer

Reference.

Detailed Explanation

exports is just a reference (shortcut) to module.exports. If you assign a new object to exports, you break the link. Always safer to return module.exports.

Code Example

module.exports vs exports?

Quick Answer

module.exports is the object that is actually returned as the result of a require call.

Detailed Explanation

exports is just a convenience variable referencing module.exports. If you assign a new value to exports (exports = ...), you break the link, and require will return the original (empty) module.exports.

Code Example

What are Streams?

Quick Answer

Streams are objects that let you read data from a source or write data to a destination in continuous chunks.

Detailed Explanation

They are memory efficient because they don't load the whole file into RAM. Four types: Readable, Writable, Duplex, Transform.

Code Example

fs.createReadStream('file.txt').pipe(res);

What is Node.js?

Quick Answer

Node.js is a JavaScript runtime built on Chrome's V8 JavaScript engine.

Detailed Explanation

It allows executing JavaScript outside the browser (server-side). It uses an event-driven, non-blocking I/O model that makes it lightweight and efficient for data-intensive real-time applications.

What is the EventEmitter class?

Quick Answer

A class in the events module that facilitates communication between objects in Node.js.

Detailed Explanation

Many Node.js objects emit events (like net.Server emits 'connection'). You can create your own emitters using on (listen) and emit (trigger).

Code Example

const ee = new EventEmitter();
ee.on('event', () => console.log('fired'));
