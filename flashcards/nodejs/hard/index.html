How does V8 Garbage Collection work?

Quick Answer

It uses a generational approach (Orinoco). Young Generation (Minor GC, Scavenge) and Old Generation (Major GC, Mark-Sweep-Compact).

Detailed Explanation

It stops the world (pauses execution) during Major GC. Node flags like --max-old-space-size control the heap limit.

Monomorphic vs Polymorphic functions (V8)?

Quick Answer

Monomorphic: Function always sees same argument shapes (fast). Polymorphic: Sees different shapes (slow).

If add(a, b) is called with integers, V8 optimizes it. If later called with strings, it de-optimizes. Keeping hidden classes stable improves performance.

What is Backpressure in Streams?

Quick Answer

A mechanism to handle the buildup of data when the write speed is slower than the read speed.

Detailed Explanation

If readable stream pushes data faster than writable stream can consume, memory swells. stream.write() returns false to signal backpressure. The system pauses reading until drain event is fired.

Code Example

if (!dest.write(chunk)) src.pause();

Worker Threads (worker_threads)?

Quick Answer

A module enabling true multi-threading in Node.js (sharing memory).

Detailed Explanation

Unlike child_process (which is process isolation), Worker Threads share memory (SharedArrayBuffer). Useful for CPU-intensive tasks (image resizing, crypto) without blocking the Event Loop.

Code Example
