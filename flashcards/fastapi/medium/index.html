routing

APIRouter?

Quick Answer

Split logic.

Detailed Explanation

Used to organize path operations into multiple files/modules. Includes prefix, tags, dependencies.

Code Example
router = APIRouter(prefix="/users")
security

Security dependency?

Quick Answer

Auth scopes.

Detailed Explanation

Advanced version of Depends to declare OAuth2 scopes required.

Code Example
Security(get_user, scopes=['read'])

Callback Routes?

Quick Answer

Webhooks documentation.

Detailed Explanation

Documenting external callbacks your API will trigger.

Code Example
callbacks=router.routes
validation

Config orm_mode?

Quick Answer

ORM compatibility.

Detailed Explanation

Pydantic V1 setting (V2 from_attributes) allowing models to read data from arbitrary objects (ORM models) instead of just dicts.

Code Example
Item.from_orm(db_item)

CORS?

Quick Answer

Cross-Origin Resource Sharing.

Detailed Explanation

Middleware (CORSMiddleware) to allow requests from different origins (browsers).

Code Example
app.add_middleware(CORSMiddleware, ...)
errors

Custom Exception Handlers?

Quick Answer

@app.exception_handler.

Detailed Explanation

Catch specific exceptions globally and return custom JSON responses.

Code Example
@app.exception_handler(UnicornException)
di

Dependency Injection?

Quick Answer

Depends.

Detailed Explanation

Mechanism to declare requirements (db session, auth user) that the framework resolves and passes to your function.

Code Example
db = Depends(get_db)
files

File Uploads?

Quick Answer

UploadFile.

Detailed Explanation

Used to receive files. Provides async methods (read, write, close). Spooled in memory/disk.

Code Example
file: UploadFile = File(...)

OAuth2 with Password?

Security utility to extract token from header. Returns the token path.

Model metadata.

Request object access?

Quick Answer

Using Request type.

Declare a parameter of type Request to access raw object (client IP, headers).

models

Response Model?

Quick Answer

Output filtering.

Detailed Explanation

Parameter in decorator response_model=Item. Automatically filters out data not in the model (like passwords) and handles serialization.

Code Example
@app.get(..., response_model=UserOut)
