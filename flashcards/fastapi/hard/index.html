def vs async def?

Quick Answer

Threadpool vs Event Loop.

Detailed Explanation
  • async def: Runs directly on the event loop. Must not block.
  • def: Runs in a separate threadpool (Starlette). Safe for blocking I/O.
Code Example
async def fast(): ...
