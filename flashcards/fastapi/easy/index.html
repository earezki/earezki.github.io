async def?

Quick Answer

Native Async.

Detailed Explanation

Define path operations with async def to use await. FastAPI runs standard def in threadpool.

Code Example
async def root(): ...

Return error.

Detailed Explanation

Standard way to return non-200 responses with details.

Code Example
raise HTTPException(status_code=404)

Path Operation Decorator?

Quick Answer

@app.get / @app.post.

Detailed Explanation

Tells FastAPI that the function below handles requests to that path and operation.

Code Example
@app.get("/")

Path Parameters?

Quick Answer

Variables in URL.

Detailed Explanation

Declared with standard Python format strings syntax.

Code Example
@app.get("/items/{item_id}")

Predefined path values?

Quick Answer

Enum class.

Detailed Explanation

Use a Python Enum to restrict possible values for a path parameter.

Code Example
class ModelName(str, Enum): ...

Pydantic Models?

Quick Answer

Data Validation.

Detailed Explanation

Classes defining shape of data. FastAPI invokes Pydantic to validate Request Body and serialize Response.

Code Example
class Item(BaseModel): name: str
params

Query Parameters?

Quick Answer

Function arguments.

Detailed Explanation

Function parameters that are not part of the path are interpreted as query parameters.

Code Example
def read(skip: int = 0, limit: int = 10)
request

Request Body?

Quick Answer

Pydantic Model argument.

Detailed Explanation

Declare it as a type hint using a Pydantic model in the path operation function.

Code Example
def create(item: Item): ...
response

Response Status Code?

Quick Answer

status_code param.

Detailed Explanation

Set default status code in the decorator.

Code Example
@app.post("/", status_code=201)
config

Tags parameter?

Quick Answer

Doc grouping.

Detailed Explanation

Argument in path decorators to group endpoints in Swagger UI.

Code Example
@app.get("/", tags=["users"])

Type Hints?

Quick Answer

Python 3.6+ standard.

Detailed Explanation

FastAPI uses them to validate data, convert types, and generate docs. No extra syntax required.

Code Example
item_id: int
params

Validating Path params?

Quick Answer

Path class.

Detailed Explanation

Similar to Query, but for path parameters.

Code Example
item_id: int = Path(ge=1)
params

Validating Query params?

Quick Answer

Query class.

Detailed Explanation

Allows adding validation (min_length, regex) and metadata (title, description) to query params.

Code Example
q: str = Query(min_length=3)
