__getattr__ usage risk?

Click to reveal  ·  Space
Quick Answer

Infinite recursion if not careful.

Explanation

If you access an attribute inside __getattr__ that also doesn't exist, it calls __getattr__ again. Access self.__dict__ or super instead.

Code Example
Be careful accessing self.x inside __getattr__
