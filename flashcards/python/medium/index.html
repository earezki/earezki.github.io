__init__ vs __new__?

Quick Answer

__new__ is the first step of instance creation (creates the object). __init__ is the second step (initializes the object).

Detailed Explanation

__new__ returns the instance of the class. __init__ takes that instance and sets initial attributes. You rarely override __new__ unless subclassing immutable types like int or str or implementing Singletons.

*args and **kwargs?

Quick Answer

*args passes variable number of non-keyword arguments (as a tuple). **kwargs passes variable number of keyword arguments (as a dictionary).

Detailed Explanation

They allow functions to accept flexible input signatures. The names args and kwargs are conventions; the asterisks are what matter.

Code Example

def foo(*args, **kwargs):
print(args) # (1, 2)
print(kwargs) # {'a': 3}
foo(1, 2, a=3)

deepcopy vs copy?

Quick Answer

copy() creates a shallow copy (new object, but references to nested objects are shared). deepcopy() recursively creates copies of all nested objects.

Detailed Explanation

If you have a list of lists, changing the inner list in a shallow copy will reflect in the original. In a deep copy, everything is independent.

Code Example

import copy
a = [[1], [2]]
b = copy.deepcopy(a)

Explain the yield keyword.

Quick Answer

yield turns a function into a generator. It pauses the function execution and returns a value to the caller, saving the state.

Detailed Explanation

When next() is called on the generator, it resumes execution immediately after the yield statement. This allows producing a sequence of values over time rather than computing them all at once.

Code Example

def count_up_to(n):
i = 1
while i <= n:
yield i
i += 1

List comprehensions create the entire list in memory. Generators (using ()) produce items one at a time and are memory efficient.

Detailed Explanation

Use generators when processing large datasets where you don't need to access all elements at once. A generator expression (x*2 for x in range(10)) returns a generator object, not a list.

How does inheritance work in Python?

Quick Answer

A class can inherit attributes and methods from a parent class.

Detailed Explanation

Inheritance allows a child class to reuse logic from a parent class. You define it by passing the parent class in parentheses after the child class name. Python supports multiple inheritance.

How does Python manage memory?

Quick Answer

Python uses a private heap containing all Python objects and data structures. It uses Reference Counting and a Garbage Collector.

Detailed Explanation

The core mechanism is reference counting: when an object's reference count drops to 0, it is deallocated. A cyclic garbage collector runs periodically to find and clean up isolated reference cycles (e.g. A refs B, B refs A).

Mutable Default Arguments pitfall?

Quick Answer

Default arguments are evaluated only once at function definition time, not every time the function is called.

Detailed Explanation

If you use a mutable object (like a list) as a default, modifications to it persist across calls. Always use None as default for mutable types.

What is the difference between return and yield?

Quick Answer

return sends a value and ends the function; yield sends a value and pauses execution.

Detailed Explanation

return terminates a function entirely. yield produces a value and suspends the function's execution, saving its state so it can resume from where it left off. This turns the function into a generator.

Code Example
def count_up_to(n):
    count = 1
    while count <= n:
        yield count
        count += 1
# Returns a generator object

What is the Global Interpreter Lock (GIL)?

Quick Answer

The GIL is a mutex that allows only one thread to hold the control of the Python interpreter at any one time.

Detailed Explanation

This means that even in a multi-threaded Python program on a multi-core CPU, only one thread can execute Python bytecode at a time. This limits CPU-bound parallelism but simplifies memory management (reference counting). For true parallelism, use multiprocessing.

Why should you avoid mutable default arguments?

Quick Answer

Because the default value is evaluated only once when the function is defined.

Detailed Explanation

If you use a mutable object (like a list or dictionary) as a default argument, that same object is shared across all calls to the function. Modifications to it persist simply because it's the same object in memory.

    return target
