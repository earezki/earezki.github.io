break vs continue?

Quick Answer

break exits the loop; continue skips the current iteration.

Detailed Explanation

break terminates the loop completely. continue jumps to the next iteration of the loop immediately.

Code Example
for i in range(5):
    if i == 3: break
    print(i)

Quick Answer

What is the use of break and continue?

Quick Answer

break exits the loop; continue skips the current iteration.

Detailed Explanation

break terminates the nearest enclosing loop completely. continue skips the rest of the code inside the loop for the current iteration and jumps to the next iteration.

Code Example
for i in range(5):
    if i == 2:
        continue  # skip 2
    if i == 4:
        break     # stop at 4
    print(i)
# Output: 0, 1, 3
