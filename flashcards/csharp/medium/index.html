async void vs async Task?

Quick Answer

Only use async void for Event Handlers. Everywhere else use async Task.

Detailed Explanation

async void methods cannot be awaited. If they throw an exception, it crashes the process (not caught by caller). async Task exceptions are captured in the Task object.

Code Example

public async void OnClick(object sender, EventArgs e) { ... }

LINQPerformance

IEnumerable vs IQueryable?

Quick Answer

IEnumerable executes query in memory (LINQ to Objects). IQueryable translates query to external store (SQL) for execution (LINQ to SQL).

Detailed Explanation

Task vs Thread?

Quick Answer

Thread is a lower-level OS concept. Task is a higher-level abstraction (Promise) executed by the Thread Pool.

Detailed Explanation

Tasks are designed for the Task Parallel Library (TPL). They are more lightweight and compose better (continuations, await). A Task might run on a new thread, an existing thread, or no thread (I/O bound).

Code Example

Task.Run(() => DoWork());

MemoryDotNet

Explain 'Garbage Collection' generations.

Quick Answer

Gen 0 (Types), Gen 1 (Survivors), Gen 2 (Long-lived).

Detailed Explanation

.NET assumes new objects die young. Gen 0 collection happens frequently (fast). Objects surviving move to Gen 1. Gen 2 (Full GC) is rare and expensive.

Quick Answer

Structs are Value Types (stack). Classes are Reference Types (heap).

What is yield return?

Quick Answer

It creates a state machine to lazily generate a sequence of values.

Detailed Explanation

The method returns an IEnumerable immediately. The code inside runs only when the consumer asks for the next item (MoveNext). This allows iterating over infinite sequences or large files without loading everything into memory.

Code Example

IEnumerable GetAll() {
yield return 1;
yield return 2;
}

OOPDelegates

What is an Event and how does it relate to Delegates?

Quick Answer

An Event is a wrapper around a Delegate that protects it from external misuse.

Detailed Explanation

With a raw public Delegate, anyone can invoke it or reset it (d = null). With an event, external subscribers can only add (+=) or remove (-=) handlers. Only the declaring class can invoke the event.

Code Example

public event EventHandler MyEvent;

MemoryDotNet

What is Boxing and Unboxing?

Quick Answer

Boxing: converting a Value Type to a Reference Type (Object). Unboxing: extracting the Value Type from the Object.

Detailed Explanation

Boxing allocates memory on the heap and copies the value. It incurs performance overhead and GC pressure. Generics (List<T>) largely eliminate the need for this.

Code Example

int i = 123;
object o = i; // Boxing
int j = (int)o; // Unboxing

  • Unboxing: Extracting value type from object (Type check + Copy). Expensive.
