ConcurrentDictionary implementation?

Quick Answer

A thread-safe dictionary implementation.

Detailed Explanation

Unlike a standard Dictionary locked with a giant lock, it uses fine-grained locking (multiple locks for different buckets) or lock-free techniques to allow high concurrency for reads and writes.

ConcurrencyThreading

Volatile keyword in C#?

Quick Answer

Indicates that a field might be modified by multiple threads that are executing at the same time.

Detailed Explanation

It disables compiler optimizations (like caching in registers) and prevents instruction reordering for that field, ensuring all threads see the most up-to-date value. Usually Interlocked or lock is preferred.

Code Example

private volatile bool _stop;

Covariance and Contravariance?

Quick Answer

Covariance (out) allows using a derived type. Contravariance (in) allows using a base type.

Detailed Explanation

Applies to Arrays, Delegates, and Generic Interfaces. IEnumerable<string> can be assigned to IEnumerable<object> (Covariant). Action<object> can be assigned to Action<string> (Contravariant).
