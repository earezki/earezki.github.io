GenericsCollections

ArrayList vs List<T>?

Quick Answer

ArrayList stores object, requiring casting and causing boxing/unboxing (slow). List<T> is generic and type-safe (fast).

Detailed Explanation

ArrayList belongs to the old non-generic collections (C# 1.0). Always prefer List<T> (C# 2.0+) to avoid runtime type errors and performance penalties.

Code Example

List numbers = new List();

KeywordsOOP

const vs readonly?

Quick Answer

const is a compile-time constant. readonly is a runtime constant.

Detailed Explanation

const values are embedded directly into the IL code at call sites. readonly fields can be set in the constructor (and vary per instance), and are looked up at runtime, allowing versioning flexibility.

Code Example

public const int Max = 100;
public readonly int id;
public MyClass(int i) { id = i; }

BasicsStrings

String vs StringBuilder in C#?

Quick Answer

String is immutable. StringBuilder is mutable.

Detailed Explanation

Concatenating strings in a loop (s += "a") creates a new string object every iteration, generating garbage. StringBuilder uses a buffer to efficiently modify the string in place.

Code Example

StringBuilder sb = new StringBuilder();
sb.Append("Hello");

usage of using statement?

Quick Answer

It ensures that IDisposable objects (like File streams, DB connections) are disposed correctly.

Detailed Explanation

It is syntactic sugar for a try-finally block where Dispose() is called in the finally block. This prevents resource leaks.

BasicsData Types

What is a Nullable Type?

Quick Answer

A value type that can also be null. Syntax: int? or Nullable<int>.

Detailed Explanation

Value types (int, float, bool) normally cannot be null. Nullable types wrap them to allow null, which is useful for databases where a numeric column might be empty. You check .HasValue or use ?? operator.

Code Example

int? x = null;
int y = x ?? 0; // 0

OOPBasics

What is the difference between ref and out parameters?

Quick Answer

ref requires the variable to be initialized before passing it. out does not, but the method must assign a value before returning.

Detailed Explanation

Both allow passing arguments by reference (aliasing). Use out when you want a method to return multiple values (like TryParse). Use ref when you want to modify an existing variable's value inside the method.

Code Example

void GetValues(out int x, ref int y) {
x = 10;
y += 5;
}
