Quick Answer

make() vs new()?

Quick Answer

Initialize vs Zeroed pointer.

Detailed Explanation
  • new(T): Allocates memory, zeroes it, returns *T.
  • make(T): Allocates and initializes specific types (slice, map, chan). Returns T.
Code Example
p := new(int)
m := make(map[string]int)
collections

make function?

Quick Answer

Initialize built-in types.

Detailed Explanation

Used for slices, maps, and channels. Allocates and initializes.

Code Example

make vs new?

Quick Answer

new(T) allocates zeroed storage for T and returns *T. make() is only for slices, maps, and channels, and returns an initialized (non-zeroed) T.

Detailed Explanation

make sets up the internal data structure (like pointers and length) required for these types to be usable.

Code Example

p := new(int) // *int
m := make(map[string]int) // map

Array vs Slice?

Quick Answer

Fixed vs Dynamic.

Detailed Explanation
  • Array: Fixed length [3]int. Value type.
  • Slice: Dynamic view over array []int. Reference type.
Code Example
slice := []int{1, 2}

Arrays vs Slices?

Quick Answer

Arrays have fixed size. Slices are dynamic, flexible views over arrays.

Detailed Explanation

Slice is a descriptor containing a pointer to an array, length, and capacity. In practice, slices ([]int) are used almost everywhere instead of arrays ([5]int).

Code Example

a := [3]int{1, 2, 3} // Array
s := []int{1, 2, 3} // Slice

Declaring variables in Go?

Quick Answer

Using var keyword (var x int = 10) or short declaration operator (x := 10) inside functions.

Detailed Explanation

:= infers the type and can only be used inside functions. var can be used for package-level variables. Go enforces unused variable errors.

Code Example

var x int = 5
y := 10 // Type inferred as int

Errors handling in Go?

Quick Answer

Go uses explicit error return values rather than exceptions.

Detailed Explanation

Functions often return (result, error). The caller must check if err != nil. This treats errors as normal values and ensures they are handled immediately.

Code Example

if err != nil {
log.Fatal(err)
}

pointers

Pointers in Go?

Quick Answer

Memory address.

Detailed Explanation

Go supports pointers (*T), allowing you to pass references to values. No pointer arithmetic is allowed (unlike C).

Code Example
p := &x
*p = 21

Pointers in Go?

Quick Answer

Go supports pointers (variables that store memory addresses) but does not support pointer arithmetic (like C).

Detailed Explanation

Use & to get the address of a variable and * to dereference (access value at address). Functions pass arguments by value; passing a pointer allows modifying the original variable.

Code Example

x := 10
p := &x
*p = 21 // x is now 21

Public vs Private visibility?

Quick Answer

Visibility is controlled by capitalization. Start with Uppercase = Exported (Public). Start with Lowercase = Unexported (Private to package).

Detailed Explanation

This applies to variables, struct fields, functions, and types. No public or private keywords exist.

Code Example

func Exported() {}
func unexported() {}

What is a struct?

Quick Answer

A typed collection of fields. It is the core building block for data in Go (similar to classes in other languages, but data-only).

Detailed Explanation

Go is not Object-Oriented in the traditional sense; it has no classes. Structs combined with methods (receivers) provide object-like behavior.

Code Example

type Person struct {
Name string
Age int
}

What is a Channel?

Quick Answer

A channel is a conduit that allows goroutines to communicate and synchronize execution by sending and receiving values.

Detailed Explanation

They are typed (chan int). Sending ch <- v and receiving v := <-ch blocks execution by default until both sender and receiver are ready.

Code Example

ch := make(chan int)
go func() { ch <- 42 }()
fmt.Println(<-ch)

What is a Goroutine?

Quick Answer

Lightweight thread managed by Go runtime.

Detailed Explanation

Functions that run concurrently. They are multiplexed onto OS threads (M:N scheduling) and have small initial stack size (2KB).

Code Example
go myFunction()

What is a Goroutine?

Quick Answer

A lightweight thread of execution managed by the Go runtime.

Detailed Explanation

Goroutines are cheaper than OS threads (starting at 2KB stack). You can launch one simply by using the go keyword before a function call.

Code Example

go func() {
fmt.Println("Async")
}()
