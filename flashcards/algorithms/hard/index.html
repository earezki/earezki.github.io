A* (A-Star) Search?

Quick Answer

An extension of Dijkstra's algorithm that uses heuristics to guide the search towards the goal faster.

Detailed Explanation

Cost function f(n) = g(n) + h(n), where g is cost from start, and h is estimated cost to goal. If h is admissible (never overestimates), A* is optimal.

Balancing Trees: AVL vs Red-Black?

Quick Answer

Both are self-balancing BSTs. AVL is strictly balanced (height diff <= 1), providing faster lookups but slower insertions/deletions due to rotations. Red-Black is loosely balanced, providing faster updates.

Detailed Explanation

Java's TreeMap and HashMap (bucket tree) use Red-Black trees.

Bellman-Ford Algorithm.

Quick Answer

Computes shortest paths from a single source to all other vertices. Slower than Dijkstra O(VE) but handles negative edge weights.

Detailed Explanation

It relaxes all edges V-1 times. A V-th relaxation allows detecting negative weight cycles (if distance creates, a negative cycle exists).

TreePath

Binary Tree Maximum Path Sum.

Quick Answer

Find the path with max sum (can start and end anywhere).

Detailed Explanation

Recursive DFS. For each node, compute maxGain from left and right subtrees. Update global max with node.val + left + right. Return node.val + max(left, right) to parent.

Dijkstra's Algorithm explanation.

Quick Answer

Finds the shortest path from a source node to all other nodes in a graph with non-negative edge weights.

Detailed Explanation

It uses a Min-Priority Queue to repeatedly select the closest unvisited node. It relaxes edges: if a shorter path to a neighbor is found through the current node, update the neighbor's distance.

Dynamic ProgrammingStrings

Edit Distance (Levenshtein).

Quick Answer

Minimum operations (insert, delete, replace) to convert word1 to word2.

Detailed Explanation

DP table dp[i][j]. If c1 == c2, dp[i][j] = dp[i-1][j-1]. Else 1 + min(insert, delete, replace).

Code Example

int[][] dp = new int[l1 + 1][l2 + 1];
// ... fill base cases ...
for (int i = 1; i <= l1; i++) {
for (int j = 1; j <= l2; j++) {
if (w1.charAt(i-1) == w2.charAt(j-1)) dp[i][j] = dp[i-1][j-1];
else dp[i][j] = 1 + Math.min(dp[i-1][j-1], Math.min(dp[i-1][j], dp[i][j-1]));
}
}

Floyd-Warshall Algorithm.

Quick Answer

An algorithm for finding shortest paths between all pairs of vertices in a weighted graph (even with negative weights, but no negative cycles).

Detailed Explanation

Dynamic programming approach O(V^3). dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]).

GraphShortest Path

Implement Dijkstra's Algorithm.

Quick Answer

Finds the shortest path from a source node to all other nodes in a graph with non-negative edge weights.

Detailed Explanation

Use a Priority Queue to always expand the cheapest node. Maintain a dist array initialized to infinity.

Code Example

public void dijkstra(List<List> adj, int src) {
PriorityQueue pq = new PriorityQueue<>(Comparator.comparingInt(node -> node.weight));
int[] dist = new int[adj.size()];
Arrays.fill(dist, Integer.MAX_VALUE);
dist[src] = 0;
pq.add(new Node(src, 0));
while (!pq.isEmpty()) {
Node curr = pq.poll();
int u = curr.id;
if (curr.weight > dist[u]) continue;
for (Node neighbor : adj.get(u)) {
if (dist[u] + neighbor.weight < dist[neighbor.id]) {
dist[neighbor.id] = dist[u] + neighbor.weight;
pq.add(new Node(neighbor.id, dist[neighbor.id]));
}
}
}
}

KMP Algorithm (Knuth-Morris-Pratt).

Quick Answer

A string searching algorithm that searches for occurrences of a 'word' within a main 'text' in O(n+m) time.

Detailed Explanation

It avoids redundant comparisons by precomputing an LPS (Longest Prefix Suffix) array. If a mismatch occurs, we know how much to skip ahead without backing up in the text.

Quick Answer

Find the median of two sorted arrays of different sizes in $O(\log(m+n))$ time.

Detailed Explanation

Use binary search on the partitions of the smaller array to find a cut such that elements on left <= elements on right.

StringsSliding Window

Minimum Window Substring.

Quick Answer

Find the smallest substring in s containing all characters of t.

Detailed Explanation

Sliding window with two pointers l, r. Expand r until window is valid (contains all chars). Then shrink l to minimize window size while keeping it valid.

BacktrackingMatrix

N-Queens Problem.

Quick Answer

Place N queens on an NxN chessboard such that no two queens attack each other.

Detailed Explanation

Use backtracking. Place a queen in a row, check validity (cols, diagonals), then recursively try to place valid queens in next rows. If stuck, backtrack.

Code Example

void solve(int row, char[][] board) {
if (row == n) { res.add(copy(board)); return; }
for (int col = 0; col < n; col++) {
if (isValid(board, row, col)) {
board[row][col] = 'Q';
solve(row + 1, board);
board[row][col] = '.';
}
}
}

Topological Sort?

Quick Answer

A linear ordering of vertices in a Directed Acyclic Graph (DAG) such that for every edge u->v, vertex u comes before v.

Detailed Explanation

Standard solution for scheduling tasks with dependencies. Can be implemented using DFS (reverse finish time) or Kahn's Algorithm (indegree counting).

PointersArrays

Trapping Rain Water.

Quick Answer

Compute how much water it is able to trap after raining.

Detailed Explanation

Two pointer approach. Maintain leftMax and rightMax. Move the pointer with smaller height inwards. Water trapped at position i is min(leftMax, rightMax) - height[i].

Code Example

int left = 0, right = height.length - 1;
int leftMax = 0, rightMax = 0;
int ans = 0;
while (left < right) {
if (height[left] < height[right]) {
if (height[left] >= leftMax) leftMax = height[left];
else ans += leftMax - height[left];
left++;
} else {
// symmetric logic for right
}
}

Travelling Salesman Problem (TSP) Class?

Quick Answer

TSP asks for the shortest possible route visiting each city exactly once and returning to origin. It is NP-Hard.

Detailed Explanation

There is no known polynomial time solution. Exact solutions use dynamic programming (Held-Karp O(n^2 * 2^n)). approximate solutions use heuristics like Simulated Annealing or MST approximation.

Trie (Prefix Tree).

Quick Answer

A tree-based data structure used for efficient retrieval of keys in a large dataset of strings.

Detailed Explanation

Each node represents a character. Useful for Autocomplete or Spell Checking. Search complexity is O(L) where L is string length, independent of total dataset size.

Union-Find (Disjoint Set) Data Structure.

Quick Answer

Keeps track of a set of elements partitioned into a number of disjoint (non-overlapping) subsets.

Detailed Explanation

Supports two operations efficiently: Union (merge two sets) and Find (determine which set an element is in). Optimized with Path Compression and Union by Rank to nearly O(1) time (Inverse Ackermann function).
