int l = i+1, r = nums.length-1;
while (l < r) {
// logic to check sum and move l/r
}
}

BFS vs DFS (Graph Traversal)?

Quick Answer

BFS (Breadth-First Search) explores neighbors layer by layer (uses Queue). DFS (Depth-First Search) explores as deep as possible along each branch before backtracking (uses Stack/Recursion).

Detailed Explanation

Use BFS to find the shortest path in an unweighted graph. Use DFS for topological sorting, finding connected components, or solving mazes.

TreesBFS

Binary Tree Level Order Traversal.

Quick Answer

Traverse tree level by level (Breadth-First Search).

Detailed Explanation

Use a Queue. Add root. While queue not empty: get size (elements in current level), pop that many elements, add their children to queue.

Code Example

public List<List> levelOrder(TreeNode root) {
List<List> res = new ArrayList<>();
if (root == null) return res;
Queue q = new LinkedList<>();
q.add(root);
while (!q.isEmpty()) {
int size = q.size();
List level = new ArrayList<>();
for (int i=0; i<size; i++) {
TreeNode node = q.poll();
level.add(node.val);
if (node.left != null) q.add(node.left);
if (node.right != null) q.add(node.right);
}
res.add(level);
}
return res;
}

Dynamic ProgrammingBasics

Climbing Stairs.

Quick Answer

Count ways to reach the top. You can take 1 or 2 steps.

Detailed Explanation

This is exactly the Fibonacci sequence. $Ways(n) = Ways(n-1) + Ways(n-2)$.

Code Example

public int climbStairs(int n) {
if (n <= 2) return n;
int a = 1, b = 2;
for (int i = 3; i <= n; i++) {
int temp = a + b;
a = b;
b = temp;
}
return b;
}

Detect Cycle in a Graph (Directed).

Quick Answer

Use DFS. Keep track of nodes currently in the recursion stack.

Detailed Explanation

If you encounter a neighbor that is already in the current recursion stack, a back-edge exists, implying a cycle. For undirected graphs, check if you visit a visited node that is not your parent.

LinkedListTwo Pointers

Detect Cycle in a Linked List (Floyd’s Cycle Finding).

Quick Answer

Use two pointers, 'slow' moving 1 step and 'fast' moving 2 steps.

Detailed Explanation

If there is a cycle, the fast pointer will eventually catch up to the slow pointer ($O(n)$). If fast reaches null, there is no cycle.

Code Example

public boolean hasCycle(ListNode head) {
if (head == null) return false;
ListNode slow = head;
ListNode fast = head;
while (fast != null && fast.next != null) {
slow = slow.next;
fast = fast.next.next;
if (slow == fast) return true;
}
return false;
}

Explain the 'Two Pointers' technique.

Quick Answer

A pattern where two pointers iterate through the data structure in different directions or speeds to save space/time.

Detailed Explanation

Example: Detecting a cycle in a linked list (Floyd's Tortoise and Hare). One moves 1 step, other moves 2 steps. If they meet, there is a cycle.

Graph Representation: Adjacency Matrix vs List?

Quick Answer

Matrix is a 2D array (V x V). List is an array of lists (V).

Detailed Explanation

Matrix takes O(V^2) space; good for dense graphs and quick edge lookups O(1). List takes O(V+E) space; good for sparse graphs and iterating neighbors.

Greedy Algorithms?

Quick Answer

Algorithms that make the locally optimal choice at each step with the hope of finding a global optimum.

Detailed Explanation

They don't always work (e.g., Knapsack problem). They work for problems like Activity Selection, Huffman Coding, or minimal spanning tree (Prim's/Kruskal's).

SortingDivide and Conquer

Implement Merge Sort.

Quick Answer

A divide-and-conquer algorithm that divides the array into halves, sorts them, and merges them.

Detailed Explanation

It guarantees $O(n \log n)$ time complexity but requires $O(n)$ extra space for the temporary arrays during merging.

Code Example

public void mergeSort(int[] arr, int l, int r) {
if (l < r) {
int m = l + (r - l) / 2;
mergeSort(arr, l, m);
mergeSort(arr, m + 1, r);
merge(arr, l, m, r);
}
}

SortingDivide and Conquer

Implement Quick Sort.

Quick Answer

Selects a 'pivot' element and partitions array so elements < pivot are on left, > pivot on right.

Detailed Explanation

Average time $O(n \log n)$, worst case $O(n^2)$. Unlike Merge Sort, it can be done in-place ($O(\log n)$ stack space).

Code Example

public void quickSort(int[] arr, int low, int high) {
if (low < high) {
int pi = partition(arr, low, high);
quickSort(arr, low, pi - 1);
quickSort(arr, pi + 1, high);
}
}
// partition method swaps elements around pivot

ArraysKadane Algorithm

Maximum Subarray Sum (Kadane's Algorithm).

Quick Answer

Find the contiguous subarray which has the largest sum.

Detailed Explanation

Iterate through array, keeping track of currentSum. If currentSum becomes negative, reset it to 0. Update maxSum at each step. Time: $O(n)$.

Code Example

public int maxSubArray(int[] nums) {
int maxSoFar = nums[0];
int currentMax = nums[0];
for (int i = 1; i < nums.length; i++) {
currentMax = Math.max(nums[i], currentMax + nums[i]);
maxSoFar = Math.max(maxSoFar, currentMax);
}
return maxSoFar;
}

Merge Sort vs Quick Sort?

Quick Answer

Both are O(n log n). Merge Sort is stable and consistent but uses O(n) extra space. Quick Sort is often faster in practice (in-place) but has a worst-case O(n^2).

Detailed Explanation

Merge Sort follows Divide and Conquer: split in half, sort halves, merge. Quick Sort picks a pivot, partitions array around it (smaller left, larger right), and recurses. Quick Sort is preferred for Arrays, Merge Sort for Linked Lists.

GraphIsland

Number of Islands.

Quick Answer

Count connected components of '1's (land) in a 2D grid.

Detailed Explanation

Iterate through grid. When a '1' is found, increment count and trigger DFS/BFS to mark all connected '1's as '0' (visited).

Code Example

public int numIslands(char[][] grid) {
int count = 0;
for(int i=0; i<grid.length; i++)
for(int j=0; j<grid[0].length; j++)
if(grid[i][j]=='1') {
dfs(grid, i, j);
count++;
}
return count;
}

Sliding Window technique?

Quick Answer

An optimization technique to convert nested loops into a single loop by maintaining a 'window' of elements that slides across the array.

Detailed Explanation

Useful for subarray problems (e.g., 'max sum of subarray of size k'). Instead of recalculating sum for the next window from scratch, add the new element and subtract the leaving element.

Dynamic ProgrammingGrid

Unique Paths.

Quick Answer

Find number of possible paths from top-left to bottom-right of m x n grid, moving only down or right.

Detailed Explanation

DP approach: dp[i][j] = dp[i-1][j] + dp[i][j-1]. The number of ways to reach a cell is sum of ways to reach cell above and cell left.

Code Example

int[][] dp = new int[m][n];
for(int i=0;i<m;i++) dp[i][0]=1;
for(int j=0;j<n;j++) dp[0][j]=1;
for(int i=1;i<m;i++) {
for(int j=1;j<n;j++) {
dp[i][j] = dp[i-1][j] + dp[i][j-1];
}
}
return dp[m-1][n-1];

TreesDFS

Validate Binary Search Tree (BST).

Quick Answer

Ensure every node follows the rule: left < node < right.

Detailed Explanation

Recursive approach passing down valid ranges (min, max). Node value must be strictly between min and max inherited from parents.

Code Example

public boolean isValidBST(TreeNode root) {
return validate(root, null, null);
}
private boolean validate(TreeNode node, Integer min, Integer max) {
if (node == null) return true;
if ((min != null && node.val <= min) || (max != null && node.val >= max)) return false;
return validate(node.left, min, node.val) && validate(node.right, node.val, max);
}

What is a Binary Search Tree (BST)?

Quick Answer

A tree where for every node, the left child is smaller and the right child is larger.

Detailed Explanation

Search, Insert, and Delete are O(h) where h is height. In a balanced BST, h = log n. In a skewed BST (worst case), h = n (like a linked list).

What is a Heap (Priority Queue)?

Quick Answer

A binary tree-based structure where the parent is always greater (Max-Heap) or smaller (Min-Heap) than its children.

Detailed Explanation

Efficient for accessing the max/min element in O(1). Insertion and Deletion are O(log n). Used in Heap Sort and Dijkstra's algorithm.

What is Dynamic Programming (DP)?

Quick Answer

An optimization technique for solving complex problems by breaking them into simpler subproblems and storing their results (Memoization) to avoid redundant computations.

Detailed Explanation

Key properties: Overlapping Subproblems (fibonacci) and Optimal Substructure (shortest path). Top-Down is recursion + memoization. Bottom-Up is iterative table filling.
