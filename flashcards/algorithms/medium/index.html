Quick Answer

Find all unique triplets in the array which gives the sum of zero.

Explanation

Sort the array. Iterate i. For each i, use two pointers (left, right) on the rest of the array to find pairs summing to -nums[i].

Code Example

Arrays.sort(nums);
for (int i = 0; i < nums.length - 2; i++) {
if (i > 0 && nums[i] == nums[i-1]) continue;
int l = i+1, r = nums.length-1;
while (l < r) {
// logic to check sum and move l/r
}
}
