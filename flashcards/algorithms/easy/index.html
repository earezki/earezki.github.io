StringsBasics

Check for Palindrome.

Quick Answer

Check if a string reads the same backward as forward.

Detailed Explanation

We can use two pointers, one at the start and one at the end, moving inwards. If characters don't match, it's not a palindrome.

Code Example

public boolean isPalindrome(String s) {
int i = 0, j = s.length() - 1;
while (i < j) {
if (s.charAt(i) != s.charAt(j)) {
return false;
}
i++;
j--;
}
return true;
}

Check if a string is a Palindrome.

Quick Answer

A palindrome reads the same forwards and backwards (e.g., 'racecar').

Detailed Explanation

Algorithm: Compare the character at start (i=0) with end (j=len-1). Increment i, decrement j. If chars mismatch, false. If i meets j, true.

ArraysHashing

Contains Duplicate.

Quick Answer

Check if any value appears at least twice in the array.

Detailed Explanation

Use a HashSet to track seen elements. If add() returns false (or contains() returns true), we found a duplicate.

Code Example

public boolean containsDuplicate(int[] nums) {
Set seen = new HashSet<>();
for (int num : nums) {
if (!seen.add(num)) {
return true;
}
}
return false;
}

Quick Answer

A simple sorting algorithm that repeatedly steps through the list, compares adjacent elements, and swaps them if they are in the wrong other.

Detailed Explanation

It 'bubbles' the largest unsorted element to the end in each pass. It is inefficient (O(n^2)) and rarely used in production, but good for educational purposes.

Detailed Explanation

Recursive: f(n) = n * f(n-1), Base case f(0) = 1. Iterative: Loop from 1 to n multiplying the accumulator.

MathBasics

Fibonacci Sequence (Iterative).

Quick Answer

Generates the $n$-th number in Fibonacci sequence where $F(n) = F(n-1) + F(n-2)$.

Detailed Explanation

Using iteration is essentially $O(n)$ time and $O(1)$ space, which is better than naive recursion ($O(2^n)$).

Code Example

public int fibonacci(int n) {
if (n <= 1) return n;
int a = 0, b = 1;
for (int i = 2; i <= n; i++) {
int temp = a + b;
a = b;
b = temp;
}
return b;
}

StringsHashing

Find First Non-Repeating Character.

Quick Answer

Return the first character that occurs only once in the string.

Detailed Explanation

Use a HashMap (or int array for ASCII) to store frequency of all characters, then traverse string again to find the first one with count 1.

Code Example

public int firstUniqChar(String s) {
int[] freq = new int[26];
for (char c : s.toCharArray()) {
freq[c - 'a']++;
}
for (int i = 0; i < s.length(); i++) {
if (freq[s.charAt(i) - 'a'] == 1) {
return i;
}
}
return -1;
}

SearchingBasics

Implement Binary Search (Iterative).

Quick Answer

An efficient algorithm for finding an item from a sorted list of items.

Detailed Explanation

It works by repeatedly dividing in half the portion of the list that could contain the item, until you've narrowed down the possible locations to just one. Time complexity: $O(\log n)$.

Code Example

public int binarySearch(int[] arr, int target) {
int left = 0;
int right = arr.length - 1;
while (left <= right) {
int mid = left + (right - left) / 2;
if (arr[mid] == target) {
return mid;
}
if (arr[mid] < target) {
left = mid + 1;
} else {
right = mid - 1;
}
}
return -1; // Not found
}

SortingBasics

Implement Bubble Sort.

Quick Answer

A simple sorting algorithm that repeatedly steps through the list, compares adjacent elements and swaps them if they are in the wrong order.

Detailed Explanation

It is named for the way smaller or larger elements 'bubble' to the top of the list. It is inefficient for large lists ($O(n^2)$) but easy to implement.

Code Example

public static void bubbleSort(int[] arr) {
int n = arr.length;
boolean swapped;
for (int i = 0; i < n - 1; i++) {
swapped = false;
for (int j = 0; j < n - i - 1; j++) {
if (arr[j] > arr[j + 1]) {
// swap arr[j] and arr[j+1]
int temp = arr[j];
arr[j] = arr[j + 1];
arr[j + 1] = temp;
swapped = true;
}
}
// If no two elements were swapped by inner loop, then break
if (!swapped) break;
}
}

MathBasics

Implement Factorial (Recursive).

Quick Answer

Calculates $n! = n \times (n-1) \times ... \times 1$.

Detailed Explanation

Base case: if $n$ is 0 or 1, return 1. Recursive step: return $n \times factorial(n-1)$.

Code Example

public long factorial(int n) {
if (n <= 1) return 1;
return n * factorial(n - 1);
}

SortingBasics

Implement Insertion Sort.

Quick Answer

Builds the final sorted array one item at a time.

Detailed Explanation

It picks an element and inserts it into the correct position in the already sorted part of the array. Effective for small or nearly sorted data.

Code Example

public void insertionSort(int[] arr) {
for (int i = 1; i < arr.length; i++) {
int key = arr[i];
int j = i - 1;
while (j >= 0 && arr[j] > key) {
arr[j + 1] = arr[j];
j = j - 1;
}
arr[j + 1] = key;
}
}

Linear Search vs Binary Search?

Quick Answer

Linear Search checks every element (O(n)). Binary Search divides the search interval in half repeatedly (O(log n)) but requires the array to be sorted.

Detailed Explanation

Linear search works on any list. Binary search is much faster for large datasets, but the overhead of sorting first might not be worth it for small or strictly dynamic datasets.

Linked List vs Array?

Quick Answer

Linked Lists consist of nodes where each node points to the next. They allow fast insertions/deletions (O(1)) but slow access (O(n)). Arrays have fast access but slow insertions.

Detailed Explanation

Linked lists are dynamic size (don't need to declare size upfront) but use more memory (pointers). Arrays are fixed size and cache-friendly (contiguous memory).

ArraysTwo Pointers

Reverse an Array.

Quick Answer

In-place reversal of an array.

Detailed Explanation

Swap elements from the ends working towards the middle.

Code Example

public void reverseArray(int[] arr) {
int start = 0;
int end = arr.length - 1;
while (start < end) {
int temp = arr[start];
arr[start] = arr[end];
arr[end] = temp;
start++;
end--;
}
}

Stack vs Queue?

Quick Answer

Stack is LIFO (Last In, First Out). Queue is FIFO (First In, First Out).

Detailed Explanation

Push/Pop operations are for Stacks (like a stack of plates). Enqueue/Dequeue operations are for Queues (like a line at a store). Stacks are used for function calls/recursion. Queues are used for buffering.

StacksBasics

Valid Parentheses.

Quick Answer

Check if the input string has valid matching brackets '()', '{}', '[]'.

Detailed Explanation

Push opening brackets onto a stack. When closing bracket is met, check if it matches the top of the stack.

Code Example

public boolean isValid(String s) {
Stack stack = new Stack<>();
for (char c : s.toCharArray()) {
if (c == '(') stack.push(')');
else if (c == '{') stack.push('}');
else if (c == '[') stack.push(']');
else if (stack.isEmpty() || stack.pop() != c) return false;
}
return stack.isEmpty();
}

What is a Hash Table?

Quick Answer

A data structure that implements an associative array abstract data type, a structure that can map keys to values.

Detailed Explanation

It uses a hash function to compute an index into an array of buckets or slots. Ideally, looking up a value is O(1). Collisions (different keys hashing to same index) are handled via chaining or open addressing.

What is an Array?

Quick Answer

An array is a collection of elements identified by index or key, stored in contiguous memory locations.

Detailed Explanation

Accessing an element by index is O(1) (instant). However, inserting or deleting elements in the middle is O(n) because subsequent elements must be shifted.

What is Big O Notation?

Quick Answer

Big O notation describes the upper bound of the complexity (time or space) of an algorithm in the worst-case scenario.

Detailed Explanation

It helps us estimate how an algorithm's performance degrades as the input size (n) grows. O(1) is constant (best), O(n) is linear, O(n^2) is quadratic (often slow).

What is Recursion?

Quick Answer

Recursion is a method where the solution to a problem depends on solutions to smaller instances of the same problem. A function calls itself.

Detailed Explanation

Every recursive function needs a 'Base Case' to stop the recursion. Without it, you get a Stack Overflow error.
