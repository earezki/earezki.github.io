Check if a string is a Palindrome.

Click to reveal  ·  Space
Quick Answer

A palindrome reads the same forwards and backwards (e.g., 'racecar').

Explanation

Algorithm: Compare the character at start (i=0) with end (j=len-1). Increment i, decrement j. If chars mismatch, false. If i meets j, true.
