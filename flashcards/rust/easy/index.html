String vs &str?

Quick Answer

Owned heap string vs String slice.

Detailed Explanation
  • String: Heap-allocated, growable, owned string type.
  • &str: Immutable reference to a sequence of UTF-8 characters (borrowed slice).
Code Example
let s: String = "hi".to_string();
let slice: &str = &s;

String vs &str?

Quick Answer

String is a heap-allocated, growable, owned string type. &str is a string slice (view into a string), usually immutable and borrowed.

Detailed Explanation

Use String when you need to own or modify the string data. Use &str for function arguments to accept both literals and String references without copying.

Code Example

let s = String::from("hello");
let slice: &str = &s[0..2];

Copy Trait?

Quick Answer

Explain Borrowing.

Quick Answer

Borrowing is accessing data without taking ownership. It creates a reference (&T or &mut T).

Detailed Explanation

You can have multiple immutable references (&T) OR exactly one mutable reference (&mut T) at a time. This rule prevents data races at compile time.

Code Example

let s1 = String::from("hello");
let len = calculate_length(&s1); // s1 borrowed

How to define a function?

Quick Answer

Using fn keyword. Parameters must have types declared. Return type is declared with ->.

Detailed Explanation

The last expression in the function body is implicitly returned (no semicolon). If you add a semicolon, it becomes a statement and returns () (unit).

Code Example

fn add(x: i32, y: i32) -> i32 {
x + y
}

Quick Answer

It is an enum that represents an optional value: either Some(T) or None.

Detailed Explanation

Rust doesn't have null. Option forces you to handle the case where a value might be missing, preventing NullPointerExceptions.

None => println!("Empty"),
}

What is Ownership in Rust?

Quick Answer

Ownership is Rust's unique feature to manage memory safety without a Garbage Collector.

Detailed Explanation

Rules: 1. Each value has a variable that is its owner. 2. There can only be one owner at a time. 3. When the owner goes out of scope, the value is dropped (memory freed).

Code Example

let s1 = String::from("hello");
let s2 = s1; // Ownership moved to s2
// println!("{}", s1); // Error: value borrowed here after move
