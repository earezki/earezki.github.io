emptyDir Volume?

Quick Answer

Temporary volume sharing Pod's lifespan.

Detailed Explanation

Code Example

  emptyDir: {}

Different Deployment Strategies?

Quick Answer

RollingUpdate (default) and Recreate.

Detailed Explanation
  • RollingUpdate: Zero downtime. Updates pods incrementally.
  • Recreate: Terminates all old pods then creates new ones. Downtime exists, but simpler if your app doesn't support version mixing.
Code Example

  type: Recreate

Liveness vs Readiness Probes?

Quick Answer

Detailed Explanation

Requests vs Limits?

Quick Answer

Requests: minimum guaranteed; Limits: maximum allowed.

Detailed Explanation

If a node has enough CPU for the Request, the pod is scheduled. If the pod tries to use more than the Limit, it is throttled (CPU) or Killed (Memory OOM).

Code Example
resources:
  requests:
    memory: "64Mi"
  limits:
    memory: "128Mi"
resources

Requests vs Limits?

Quick Answer

Guaranteed vs Max Allowable.

Detailed Explanation
  • Requests: Minimum resources required (used for scheduling).
  • Limits: Maximum resources allowed (throttled or OOMKilled if exceeded).
Code Example
resources:
  limits: { memory: "128Mi" }
