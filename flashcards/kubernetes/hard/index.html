Cluster Autoscaler vs HPA?

Quick Answer

HPA scales Pods; Cluster Autoscaler scales Nodes.

Detailed Explanation
  • HPA: Adds more pods when load is high.
  • Cluster Autoscaler: Adds more Nodes (VMs) when there are pending pods that cannot be scheduled due to resource starvation.

How does externalTrafficPolicy: Local work?

Quick Answer

Preserves client source IP.

Detailed Explanation

By default (Cluster), traffic hitting a Node might be SNAT'd and routed to a Pod on another Node (losing source IP). Local drops traffic if the Node has no local Pods, but preserves IP for local Pods.

Code Example
externalTrafficPolicy: Local

How does CNI work?

Quick Answer

Container Network Interface standard.

Detailed Explanation

K8s doesn't implement networking itself. It offloads it to CNI plugins (Calico, Flannel, Weave). The kubelet calls the CNI plugin to set up the network interface when a pod starts.

Code Example

HPA vs VPA?

Quick Answer

Horizontal vs Vertical scaling.

Detailed Explanation
  • HPA (Horizontal Pod Autoscaler): Adds/removes Pod replicas based on CPU/Memory.
  • VPA (Vertical Pod Autoscaler): Adjusts CPU/Memory requests/limits of existing Pods (requires restart usually).

Defined by files in a specific directory (e.g., /etc/kubernetes/manifests). Used to bootstrap the control plane components themselves (etcd, kube-apiserver) as they run inside pods too.

What is an Admission Controller?

Quick Answer

A piece of code that intercepts requests to the API server before persistence.

Detailed Explanation

Two types: Validating (rejects bad config) and Mutating (modifies config, e.g., injecting sidecars). Webhooks are commonly used to implement them.

Code Example

What is an Operator?

Quick Answer

A method of packaging, deploying, and managing a Kubernetes application.

Detailed Explanation

It combines CRDs and a custom Controller. The Controller encodes human operational knowledge (how to backup, how to upgrade) to manage the custom resources automatically.

Code Example
Prometheus Operator, Postgres Operator.

What is CNI?

Quick Answer

Container Network Interface.

Detailed Explanation

A specification and libraries for writing plugins to configure network interfaces in Linux containers. Kubernetes uses CNI plugins (Calico, Flannel) to handle Pod networking.

What is CRI (Container Runtime Interface)?

Quick Answer

API that allows Kubelet to use different container runtimes.

Detailed Explanation

Docker was hardcoded originally. CRI allowed decoupling. Now K8s uses Containerd or CRI-O directly via CRI, and DockerShim was removed.

Code Example
gRPC API for container management.
