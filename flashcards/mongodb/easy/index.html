Quick Answer

Greater Than ($gt) and Less Than ($lt) query operators.

$in operator?

Quick Answer

Match list.

Detailed Explanation

Selects documents where value of a field equals any value in the specified array.

Code Example
{ status: { $in: ["A", "B"] } }
query

$or?

Quick Answer

Logical OR.

Detailed Explanation

Joins query clauses with a logical OR.

Code Example
{ $or: [ {a:1}, {b:2} ] }

$set operator?

Quick Answer

Update field.

Detailed Explanation

Used in update operations to set the value of a field. If field doesn't exist, it's created.

Code Example
{$set: { status: "active" }}
UpdateOperators

$set operator?

Quick Answer

Updates specific fields in a document without overwriting the whole document.

Detailed Explanation

If the field doesn't exist, it adds it. db.coll.update(query, { $set: { status: 'active' } }).

DeleteBasics

deleteOne vs deleteMany?

Quick Answer

deleteOne removes the first matching document. deleteMany removes all matches.

Detailed Explanation

Basic CRUD operations. Returns a count of deleted documents.

Code Example

db.users.deleteMany({ status: "banned" })

find() vs findOne()?

Quick Answer

Cursor vs Single Document.

Detailed Explanation
  • find(): Selects documents in a collection and returns a cursor to the selected documents.
  • findOne(): Returns the first document that satisfies the specified query criteria.
Code Example
db.users.find({ age: 18 })

IndexBasics

Value of using Indexes?

Quick Answer

Indexes improve query speed by avoiding full collection scans.

Detailed Explanation

Without an index, MongoDB must inspect every document. Works similar to SQL B-Tree indexes.

Code Example

db.users.createIndex({ email: 1 })

What is _id?

Quick Answer

Primary Key.

Detailed Explanation

A unique identifier for every document in MongoDB. If not provided, MongoDB adds one automatically (ObjectId type). It is indexed.

Code Example

basics

What is a Collection?

Quick Answer

Group of documents.

Detailed Explanation

Analogous to a table in RDBMS. Collections exist within a single database. They do not enforce a schema.

basics

What is a Document?

Quick Answer

Record in MongoDB.

Detailed Explanation

A record in a MongoDB collection and the basic unit of data. Documents are analogous to JSON objects but exist in the database in a more type-rich format known as BSON.

Code Example
{ "name": "mongo", "type": "db" }
basics

What is BSON?

Quick Answer

Binary JSON.

Detailed Explanation

Binary-encoded serialization of JSON-like documents. It extends the JSON model to provide additional data types (e.g. Date, ObjectId, BinData) and to be efficient for encoding and decoding.

What is MongoDB?

NoSQL Document Database.

Detailed Explanation

NoSQLBasics

What is MongoDB?

Quick Answer

A document-oriented NoSQL database.

Detailed Explanation

It stores data in BSON (Binary JSON) format. It is schema-less (flexible), allowing different fields in documents within the same collection.

Code Example

db.users.insertOne({ name: "Alice", age: 25 })
