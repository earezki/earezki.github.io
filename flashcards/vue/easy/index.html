mounted lifecycle hook?

Click to reveal  ·  Space
Quick Answer

Called after the instance has been mounted (DOM is ready).

Explanation

It is the equivalent of componentDidMount in React. Good place to access the DOM directly or start API calls.

Code Example

onMounted(() => { console.log('Ready') })
