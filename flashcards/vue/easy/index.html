ConditionalsDirectives

v-if vs v-show?

Quick Answer

v-if conditionally renders the element (adds/removes from DOM). v-show toggles CSS display: none.

Detailed Explanation

Use v-if if the condition is rarely changed (higher toggle cost). Use v-show if you toggle frequently (higher initial render cost, but cheap toggle).

Computed Properties?

Quick Answer

Properties that are derived from other reactive data, cached based on dependencies.

Detailed Explanation

A computed property only re-evaluates when its reactive dependencies change. A Method runs every time a re-render happens. Use Computed for performance.

Code Example

ComponentsComposition API

Options API vs Composition API?

Quick Answer

Options API organizes code by option type (data, methods). Composition API organizes code by logical concern (setup).

Detailed Explanation

Vue 2 used Options API. Vue 3 introduced Composition API (inspired by React Hooks) to allow better code reuse and TypeScript support.

Code Example

setup() { const count = ref(0); return { count } }

What is Two-Way Binding?

Quick Answer

Syncing data between the model and the input element automatically.

Detailed Explanation

Implemented using v-model. Under the hood, it binds value prop and listens to input event. <input v-model="msg"> equals <input :value="msg" @input="msg=$event.target.value">.
