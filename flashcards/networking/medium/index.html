traceroute command?

Quick Answer

Displays the path (route) and measuring transit delays of packets across an IP network.

Detailed Explanation

It sends packets with increasing TTL (Time-To-Live). First router decrements TTL to 0 and sends 'Time Exceeded'. Second router does same. This reveals every hop.

Code Example

traceroute google.com

ProtocolResolving

ARP Protocol?

Quick Answer

Address Resolution Protocol. Maps an IP address to a MAC address.

Detailed Explanation

When you want to send data to 192.168.1.5, you broadcast 'Who has 192.168.1.5?'. That device replies 'I have it, my MAC is AA:BB:CC...'. Your device caches this.

Code Example

arp -a

ArchitectureResilience

Forward Proxy vs Reverse Proxy?

Quick Answer

Forward Proxy acts on behalf of client (anonymity, filtering). Reverse Proxy acts on behalf of server (load balancing, caching).

Detailed Explanation

Forward Proxy sits before the client. Reverse Proxy (like NGINX) sits before the web servers and shields them from direct internet access.

ApplicationTransfer

FTP vs SFTP?

Quick Answer

FTP sends data (and passwords!) in plain text. SFTP (SSH File Transfer Protocol) sends data over an encrypted SSH connection.

Detailed Explanation

Never use FTP on public networks. SFTP runs on port 22 by default.

SecurityEncryption

How does HTTPS work (TLS Handshake)?

Quick Answer

Uses TLS/SSL to encrypt traffic.

Detailed Explanation
  1. Client Hello (Supported ciphers). 2. Server Hello (Certificate, Public Key). 3. Client verifies Cert. 4. Key Exchange (Create symmetric Session Key). 5. Encrypted communication begins.
ApplicationWeb

WebSocket Protocol?

Quick Answer

Provides full-duplex communication channels over a single TCP connection.

Detailed Explanation

Unlike HTTP (request-response), WebSocket keeps the connection open, allowing the server to push real-time data to the client (Chat apps, Stock tickers). Handshake starts as HTTP Upgrade.

Code Example

ws://example.com/socket

SecurityAttacks

What is a DDoS Attack?

Quick Answer

Distributed Denial-of-Service. Flooding a server with traffic from multiple sources to make it unavailable.

Detailed Explanation

Types: Volumetric (saturate bandwidth), Protocol (consume server resources like TCP tables - SYN Flood), Application Layer (heavy requests causing CPU spike).

ScalingTraffic

What is NAT (Network Address Translation)?

Quick Answer

Remapping an IP address space into another.

Detailed Explanation

Classic SNAT (Source NAT) allows multiple devices on a home LAN (private IPs like 192.168.x.x) to share a single public IP address provided by the ISP to access the Internet.

NetworkSubnet

What is Subnet Mask?

Quick Answer

A 32-bit number that masks an IP address, and divides the IP address into network address and host address.

Detailed Explanation

Example: 255.255.255.0 (/24). It tells the router 'The first 3 bytes are the Network ID, the last byte is the specific device ID'.

ModelOSI

What is the OSI Model?

Quick Answer

Open Systems Interconnection model. A conceptual framework used to describe the functions of a networking system.

Detailed Explanation

7 Layers: 1.Physical, 2.Data Link, 3.Network (IP), 4.Transport (TCP/UDP), 5.Session, 6.Presentation, 7.Application (HTTP). Mnemonic: 'Please Do Not Throw Sausage Pizza Away'.
