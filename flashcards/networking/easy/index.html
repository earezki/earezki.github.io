HTTPCodes

Common HTTP Status Codes?

Quick Answer

2xx (Success), 3xx (Redirect), 4xx (Client Error), 5xx (Server Error).

Detailed Explanation

200 OK, 301 Moved Permanently, 400 Bad Request, 401 Unauthorized, 404 Not Found, 500 Internal Server Error, 502 Bad Gateway.

HardwareLayer 2

MAC Address?

Quick Answer

Media Access Control Address. A unique identifier assigned to a network interface controller (NIC).

Detailed Explanation

It is burned into the hardware (physically). Used for communication within a local network segment (Layer 2 of OSI).

Code Example

ifconfig

HardwareLayer 3

Router vs Switch?

Quick Answer

Switch connects devices on the same local network (LAN). Router connects different networks (LAN to WAN).

Detailed Explanation

Switch operates at Layer 2 (MAC addresses). Router operates at Layer 3 (IP addresses) and routes packets mostly to the internet.

ModelBasics

TCP vs UDP?

Quick Answer

TCP is connection-oriented and reliable. UDP is connectionless and fast.

Detailed Explanation

TCP guarantees delivery, order, and error check (Web, Email). UDP sends packets without checking if they arrive (Streaming, Gaming, DNS).

PortsBasics

What is a Port?

Quick Answer

A logical endpoint for communication.

Detailed Explanation

An IP address identifies the machine. A port identifies the specific application/process running on that machine. (Total 65535 ports).

ProtocolsBasics

What is an IP Address?

Quick Answer

Internet Protocol Address. A numerical label assigned to each device connected to a computer network.

Detailed Explanation

IPv4 (32-bit, e.g. 192.168.1.1) and IPv6 (128-bit). It serves two functions: host or network interface identification and location addressing.

ToolsBasics

What is DHCP?

Quick Answer

Dynamic Host Configuration Protocol.

Detailed Explanation

It is a network management protocol used on UDP/IP networks. Setups a DHCP server to automatically assign IP addresses to computers wanting to join the network.

DNSBasics

What is DNS?

Quick Answer

Domain Name System. The phonebook of the Internet.

Detailed Explanation

It translates human-readable domain names (www.google.com) to IP addresses (142.250.72.68) so browsers can load resources.

Code Example

nslookup google.com

HTTPBasics

What is HTTP?

Quick Answer

HyperText Transfer Protocol. The foundation of data communication for the World Wide Web.

Detailed Explanation

A request-response protocol between a client (browser) and a server. Standard ports are 80 (HTTP) and 443 (HTTPS).

AddressingBasics

What is Localhost (127.0.0.1)?

Quick Answer

A loopback interface that allows a computer to communicate with itself.

Detailed Explanation

Crucial for testing network software without a physical network card or internet connection.

Code Example

ping 127.0.0.1
