Anycast vs Unicast vs Multicast?

Quick Answer

Unicast: 1-to-1. Multicast: 1-to-Many. Anycast: 1-to-Nearest.

Detailed Explanation

Anycast (used by CDNs/DNS) announces the same IP from multiple locations. BGP routes the user to the topologically closest server. Useful for latency reduction and DDoS mitigation.

ArchitectureCDN

How does a CDN work?

Quick Answer

Content Delivery Network. Distributed servers that cache content closer to the user.

Detailed Explanation

When you request an image, DNS resolution directs you to the nearest Edge Server. If edge misses, it pulls from Origin and caches it. Reduces latency and bandwidth costs.

SecurityCORS

Preflight Requests (OPTIONS)?

Quick Answer

A check browser makes before sending complex Cross-Origin requests.

Detailed Explanation

If you send a POST with JSON or custom headers cross-origin, browser sends OPTIONS first. Server must reply with Access-Control-Allow-Methods and Allow-Headers.

TransportSCTP

SCTP Protocol?

Quick Answer

Stream Control Transmission Protocol. A message-oriented, multi-homing protocol.

Detailed Explanation

A mix of TCP and UDP. It offers reliability like TCP but supports multi-streaming (solving HOL blocking before HTTP/2) and multi-homing (using multiple IP addresses for redundancy). Used in Telecom (Signaling).

ProtocolOptimization

TCP 3-Way Handshake and 4-Way Teardown?

Quick Answer

Connect: SYN -> SYN/ACK -> ACK. Disconnect: FIN -> ACK, FIN -> ACK.

Detailed Explanation

Handshake establishes sequence numbers. Teardown requires 4 steps because connection is full-duplex (each side must close its sending stream independently).

ProtocolControl

TCP Flow Control vs Congestion Control?

Quick Answer

Flow Control protects the receiver from being overwhelmed (Window size). Congestion Control protects the network from being overwhelmed.

Detailed Explanation

Flow Control uses Sliding Window. Congestion Control uses algorithms like Slow Start, Congestion Avoidance, Fast Retransmit (TCP Reno/Cubic).

SecurityArchitecture

What is a VPN vs a Proxy?

Quick Answer

Proxy only tunnels specific app traffic (browser). VPN creates an encrypted tunnel for the entire OS network stack.

Detailed Explanation

VPN adds a virtual network interface (tun/tap). It encapsulates IP packets inside other packets.

SecurityAttacks

What is ARP Spoofing (Man-in-the-Middle)?

Quick Answer

Attacker sends fake ARP messages connecting their MAC address with the IP of the default gateway.

Detailed Explanation

The victim starts sending all internet traffic to the attacker instead of the router. The attacker can inspect/modify traffic before forwarding it.

RoutingBGP

What is BGP?

Quick Answer

Border Gateway Protocol. The protocol that runs the internet core.

Detailed Explanation

It manages how packets are routed between Autonomous Systems (AS) like ISPs. It is a path-vector protocol. Misconfiguration can take down large parts of the internet.

ProtocolNextGen

What is HTTP/2 and HTTP/3?

Quick Answer

HTTP/2 introduces Multiplexing (binary, single TCP conn). HTTP/3 uses QUIC (UDP) to solve Head-of-Line blocking.

Detailed Explanation

HTTP/1.1 had Head-of-Line blocking. HTTP/2 fixed it at App layer but suffered at TCP layer. HTTP/3 replaces TCP with QUIC to fix packet-loss delays.
