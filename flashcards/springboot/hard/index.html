How does the Spring Security filter chain work?

Quick Answer

Spring Security installs a single filter known as DelegatingFilterProxy into the Servlet container. This proxy delegates to a FilterChainProxy, which manages a list of SecurityFilterChains. How to solve the 'Circular Dependency' problem?

Quick Answer

It usually indicates bad design. Fix it by refactoring (move common logic to a 3rd class), using @Lazy injection, or Setter injection.

Detailed Explanation

If Bean A needs B and B needs A, Spring can't create either. @Lazy delays the resolution of one dependency until it's actually used, allowing the startup to proceed. Setter injection also allows creating the object first and injecting dependencies later.

Code Example

@Autowired
public A(@Lazy B b) { this.b = b; }
