Difference between @Controller and @RestController?

Quick Answer

@Controller is for traditional MVC (returning Views/HTML). @RestController is for REST APIs (returning data like JSON/XML).

Detailed Explanation

@RestController is essentially @Controller + @ResponseBody. With @Controller, you need to add @ResponseBody to every method if you want to return raw data. @RestController assumes every method writes directly to the response body.

Code Example

@RestController
class MyApi {
@GetMapping("/")
public String home() { return "Hello"; }
}

How to disable Security for a specific path?

Quick Answer

By configuring the SecurityFilterChain bean.

Detailed Explanation

You use http.authorizeHttpRequests(). Use .requestMatchers("/public/**").permitAll() to allow access without authentication.

Code Example

@Bean
public SecurityFilterChain filterChain(HttpSecurity http) throws Exception {
http
.authorizeHttpRequests(auth -> auth
.requestMatchers("/public").permitAll()
.anyRequest().authenticated()
);
return http.build();
}

What is @Transactional?

Quick Answer

Ensures that a method runs within a database transaction.

Detailed Explanation

If the method completes successfully, the transaction is committed. If an unchecked exception is thrown, it rolls back automatically.

Code Example

}

Quick Answer

It is a mechanism that automatically configures your Spring application based on the jar dependencies that you have added.

Detailed Explanation

For example, if HSQLDB is on your classpath, and you haven't manually configured any database connection beans, then Spring Boot auto-configures an in-memory database. This intelligent guessing significantly reduces the need for explicit XML or Java-based configuration.

What is Embedded Server in Spring Boot?

Quick Answer

An embedded server means the servlet container (Tomcat, Jetty, Undertow) is part of the application JAR, not an external software installed on the machine.

Detailed Explanation

This flips the traditional deployment model. Instead of the server hosting the app (Server -> App), the app hosts the server (App -> Server). This makes Spring Boot applications self-contained and easy to deploy in containers (Docker).
