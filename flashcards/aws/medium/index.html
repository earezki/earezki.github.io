API Gateway Authorizers?

Click to reveal  ·  Space
Quick Answer

Controls access to your API.

Explanation

Authorizers validate requests before reaching Lambda. Core functionality: Authentication and authorization. Internal mechanics: Token validation, policy generation. Recommended practices: Use Cognito for user auth; Lambda for custom logic. Common mistakes: Exposing sensitive data in tokens; not caching authorizers. Practical use cases: Secure APIs, microservices. Performance: Caching reduces latency. Cost: Authorizer invocations charged.

Code Example

Lambda Authorizer function

def lambda_handler(event, context):
token = event.get('authorizationToken')
method_arn = event['methodArn']

if not token:
    raise Exception('Unauthorized')

# Validate token (e.g., JWT)
try:
    # Decode and verify JWT
    payload = jwt.decode(token, 'secret', algorithms=['HS256'])
    principal_id = payload['user_id']
    
    # Generate policy
    policy = {
        'principalId': principal_id,
        'policyDocument': {
            'Version': '2012-10-17',
            'Statement': [
                {
                    'Action': 'execute-api:Invoke',
                    'Effect': 'Allow',
                    'Resource': method_arn
                }
            ]
        }
    }
    return policy
except jwt.ExpiredSignatureError:
    raise Exception('Token expired')
except jwt.InvalidTokenError:
    raise Exception('Invalid token')

IdentitySource: method.request.header.Authorization
