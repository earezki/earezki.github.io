Quick Answer

GSI vs LSI (Secondary Indexes)?

Quick Answer

Global Secondary Index (GSI) can have different Partition Key. Local Secondary Index (LSI) shares Partition Key but different Sort Key.

Detailed Explanation

GSI is eventually consistent and stores data separately (more WCU cost). LSI must be created at table creation time.
