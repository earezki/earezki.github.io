SQS vs SNS?

Quick Answer

SQS (Simple Queue Service) is 1-to-1 (Pull). SNS (Simple Notification Service) is 1-to-Many (Push).

Detailed Explanation

Use SQS to buffer requests and decouple rate of producer from consumer. Use SNS to broadcast messages to multiple subscribers (Email, Lambda, HTTP).
