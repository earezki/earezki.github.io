bulk_create?

Click to reveal  ·  Space
Quick Answer

Batch insert.

Explanation

Efficiently inserts a list of objects into the database in one query (or few batches). Caveat: doesn't call save()/signals.

Code Example
Model.objects.bulk_create([...])
