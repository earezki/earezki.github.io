orm

F() expressions?

Quick Answer

Database-side operations.

Detailed Explanation

Object representing the value of a model field. Allows referring to model field values in database queries (e.g. incrementing a counter atomically/race-free).

Code Example
product.update(price=F('price') + 1)
orm

prefetch_related?

Quick Answer

Optimization (SQL IN).

Detailed Explanation

Performance booster. Does a separate lookup for related objects (Many-to-Many or Reverse FK) and joins in Python.

Code Example
User.objects.prefetch_related('groups')
orm

Q objects?

Quick Answer

Complex lookups.

Detailed Explanation

Object used to encapsulate a collection of keyword arguments. Required for complex queries like OR (|) or NOT (~).

Code Example
filter(Q(x=1) | Q(y=2))
orm

select_related vs prefetch_related?

Quick Answer

Join vs Extra Query.

Detailed Explanation
  • select_related: Follows Foreign Keys. Performs SQL JOIN. Best for One-to-One/Many-to-One.
  • prefetch_related: Does separate lookup and joins in Python. Best for Many-to-Many/One-to-Many.
Code Example
Entry.objects.select_related('blog')
orm

select_related?

Quick Answer

Optimization (SQL JOIN).

Detailed Explanation

Performance booster. Follows foreign-key relationships in the query execution to avoid N+1 problem.

Code Example
Entry.objects.select_related('blog')
