What is Next.js?

Quick Answer

A React framework for production.

Detailed Explanation

It adds features that React lacks out-of-the-box, such as Server-Side Rendering (SSR), Static Site Generation (SSG), file-system based routing, and API routes.

DataSSR

What is Server-Side Rendering (SSR)?

Quick Answer

HTML is generated on each request.

Detailed Explanation

Useful for pages that show frequently changing data (like a user dashboard) that cannot be pre-built. It increases TTFB (Time to First Byte) compared to SSG but ensures data freshness.

Code Example

export async function getServerSideProps() { ... }

RenderingSSG

What is Static Site Generation (SSG)?

Quick Answer

HTML is generated at build time.

Detailed Explanation

The pre-rendered HTML is reused for each request. It is the fastest rendering method and can be cached by CDNs easily. Used for blogs, docs, marketing pages.

Code Example

export async function getStaticProps() { ... }
