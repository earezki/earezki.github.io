ServerEdge

Edge API Routes vs Node.js API Routes?

Quick Answer

Edge routes run on V8 Edge Runtime (like Cloudflare Workers), Node.js routes run on standard AWS Lambda/Node.

Detailed Explanation

Edge is faster (no cold start, closer to user) but has limited API support (no fs, eval, or Node-specific modules). Useful for high-volume, low-latency tasks like redirects or simple auth.

Code Example

export const config = { runtime: 'edge' };

Hard Navigation vs Soft Navigation?

Quick Answer

Hard: Browser reloads the document (state lost). Soft: Next.js replaces content in DOM (state preserved).

Detailed Explanation

In App Router, caching is aggressive. Navigating back/forward often uses the Client-side Router Cache without hitting the server. router.refresh() forces a re-fetch effectively performing a soft reload.

What is Script Optimization (Worker strategy)?

Quick Answer

Offloads script execution to a web worker using Partytown.

Detailed Explanation

The strategy="worker" option in next/script moves heavy third-party scripts (like Analytics, Pixel) off the main thread, keeping the UI responsive (Interaction to Next Paint). Next.js integrates experimental support for Partytown.

What is Turbopack?

Quick Answer

A Rust-based bundler intended to replace Webpack in Next.js.

Detailed Explanation

It caches the result of every function in the build pipeline. It claims to be 700x faster than Webpack. It powers next dev in newer versions (--turbo), speeding up HMR significantly.
