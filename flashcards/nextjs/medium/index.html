getStaticPaths purpose?

Quick Answer

Used with getStaticProps in dynamic routes to specify which paths should be pre-rendered at build time.

Detailed Explanation

If you have pages/posts/[id].js, getStaticPaths tells Next.js: "Build /posts/1 and /posts/2". The fallback property determines what happens for paths not in the list (404, Blocking, or Fallback).

Code Example

return { paths: [...], fallback: 'blocking' };
