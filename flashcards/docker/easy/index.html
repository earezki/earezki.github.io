How do you expose a port in Docker?

Quick Answer

You use the -p or --publish flag with docker run, mapping a host port to a container port.

Detailed Explanation

By default, a container's network represents a private environment. To access a service running inside a container from your host machine (e.g., localhost), you must map the port using -p <host_port>:<container_port>.

Code Example

docker run -p 3000:80 my-web-app

Access via localhost:3000, which forwards to port 80 inside

How do you list running containers?

Quick Answer

Use the command docker ps.

Detailed Explanation

How do you stop a running container?

Quick Answer

Use the command docker stop <container_id_or_name>.

Detailed Explanation

This command sends a SIGTERM signal to the main process inside the container, allowing it to shut down gracefully. If it doesn't stop within a timeout, a SIGKILL can be sent.

What is a Docker Volume?

Quick Answer

A Volume is the preferred mechanism for persisting data generated by and used by Docker containers.

Detailed Explanation

Containers are ephemeral; when they are deleted, their writable layer is lost. Volumes are stored outside the container's filesystem (managed by Docker) and survive container removal. They are essential for databases and persistent file storage.

Code Example

docker run -v my_volume:/var/lib/mysql mysql

Detailed Explanation

It serves as the recipe for creating a Docker image. It includes instructions like FROM (base image), COPY (adding files), RUN (installing dependencies), and CMD (what to run when the container starts).

RUN npm install
COPY . .

What is the difference between an Image and a Container?

Quick Answer

An Image is a read-only template used to create containers, while a Container is a running instance of an image.

Detailed Explanation

Think of an image as a class in object-oriented programming and a container as an instance of that class. An image contains the code and binaries, but it is inert. When you run an image, it becomes a container, which has a writable layer and is an active process.
