variance

Explain Covariance and Contravariance in TypeScript.

Quick Answer

Covariance relates to return types; Contravariance relates to argument types.

Detailed Explanation

TypeScript function compatibility is bivariant in specific cases (parameters) for convenience, but generally, return types are covariant (can return a detailed subtype) and arguments are contravariant (must accept a broader supertype).

Code Example
// A function that handles Animals can handle Dogs (Contravariance of args)
// A function returning a Dog is a valid function returning an Animal (Covariance of return)

Explain Variance: Covariance vs Contravariance in TypeScript.

Quick Answer

Covariance allows specific types to be assigned to broader types (common for return values), while Contravariance allows broader types to be assigned to specific types (common for function arguments).

Detailed Explanation

TypeScript is generally covariant. For example, Dog is a Animal, so Promise<Dog> is assignable to Promise<Animal> (covariance). However, function parameters are contravariant (with strictFunctionTypes). A function expecting an Animal can theoretically accept a function that handles Object (broader), but not one that only handles Dog (narrower), because it might be called with a Cat.

Code Example

type Consumer = (a: T) => void;
let acceptAnimal: Consumer = (a: Animal) => {};
let acceptDog: Consumer = (d: Dog) => {};

// acceptDog = acceptAnimal; // OK (Contravariance)
// acceptAnimal = acceptDog; // Error (Unsafe)

How does the infer keyword work within conditional types?

What are Conditional Types in TypeScript?

Quick Answer

Conditional types select one of two possible types based churn on a condition expressed as T extends U ? X : Y.

Detailed Explanation

They work like ternary operators for types. If T is assignable to U, the type resolves to X, otherwise Y. This is the foundation of many advanced utility types like Exclude, Extract, and NonNullable.

Code Example

}

What is 'Branding' or Nominal Typing in TypeScript?

Quick Answer

Since TypeScript is structural, Branding is a technique to simulate Nominal Typing by adding a unique 'brand' property to a type to distinguish it from other structurally identical types.

Detailed Explanation

Sometimes you want to differentiate between two strings (e.g., UserId and PostId) so you don't accidentally mix them up. By intersecting a base type with an object containing a unique readonly field (the brand), you force the compiler to treat them as distinct, even if they are both just strings at runtime.

Code Example

type USD = number & { __brand: "USD" };
type EUR = number & { __brand: "EUR" };

let dollars = 10 as USD;
let euros = 10 as EUR;

// dollars = euros; // Error

What is Distributive Conditional Types?

Quick Answer

When a conditional type acts on a generic type that is a Union, it distributes over the union members.

Detailed Explanation

If you have T extends U ? X : Y and T is A | B, the result is resolved as (A extends U ? X : Y) | (B extends U ? X : Y). This behavior is used to filter unions (like Exclude). To prevent distribution, you can wrap the types in tuples [T] extends [U].

Code Example

type ToArray = T extends any ? T[] : never;
type StrOrNum = string | number;
type Result = ToArray; // string[] | number[]

What is the satisfies operator?

Quick Answer

satisfies validates that an expression matches a type but preserves the specific type of the expression for inference purposes.

Detailed Explanation

Unlike type assertion (as) or simple annotation (: Type), satisfies checks conformity without widening the type. This means if a property satisfies a union string | number but is actually a number, the resulting variable retains the metadata that it is a number.

Code Example

type Colors = "red" | "green" | "blue";
type RGB = [number, number, number];

const palette = {
red: [255, 0, 0],
green: "#00ff00",
blue: [0, 0, 255]
} satisfies Record<Colors, string | RGB>;

// palette.red is inferred as [number, number, number], methods like .map() work.
