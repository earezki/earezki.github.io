unknown vs any?

Quick Answer

unknown is the type-safe counterpart of any.

Detailed Explanation

You can assign anything to unknown, but you cannot do anything with it (access properties, call methods) until you assert its type or check it. With any, you can do anything (unsafe).

Code Example
let val: unknown = 10;
if (typeof val === "number") val.toFixed();

Quick Answer

Abstract classes are base classes that cannot be instantiated directly and often contain abstract methods that must be implemented by derived classes.

Detailed Explanation

How does keyof operator work?

Quick Answer

The keyof operator takes an object type and produces a string or numeric literal union of its keys.

Detailed Explanation

keyof is essential for creating dynamic, safe property accessors. If you have type T, keyof T represents any valid property name of T. This prevents typos when accessing properties dynamically.

Code Example

logic of Intersection Types (&)?

Quick Answer

Intersection types combine multiple types into one. The resulting type has all the properties of all the combined types.

Detailed Explanation

While union types (|) say a value is one or the other, intersection types (&) say a value is one and the other. This is commonly used for mixins or combining definitions. An object of type A & B must satisfy the contract of both interface A and interface B.

Code Example

interface ErrorHandling {
success: boolean;
error?: { message: string };
}

interface ArtworksData {
artworks: { title: string }[];
}

type ArtworksResponse = ArtworksData & ErrorHandling;

What are Generics in TypeScript?

Quick Answer

A way to create reusable components that work with a variety of types.

Detailed Explanation

Generics allow you to define a component (like a function or class) that doesn't just work with one specific type, but with a type variable passed in by the user. This preserves type safety while remaining flexible.

Code Example
function identity<T>(arg: T): T {
    return arg;
}
let output = identity<string>("myString");

What are Generics in TypeScript?

Quick Answer

Generics provide a way to create reusable components that can work with a variety of types while retaining type safety.

Detailed Explanation

Generics allow you to define a function, class, or interface that accepts a type parameter (often denoted as <T>). This allows you to capture the type passed in by the user (or inferred) and use it throughout the component, ensuring that the input and output types are consistent. This is superior to using any because it prevents information loss.

Code Example

}

What are Mapped Types?

Quick Answer

Mapped Types allow you to create new types by iterating over property keys of an existing type.

Detailed Explanation

What are Type Guards?

Quick Answer

Type Guards are expressions that perform a runtime check usually returning a boolean, which allows TypeScript to narrow down a specific type within a conditional block.

Detailed Explanation

TypeScript needs help knowing the specific type of a variable when it could be one of many (a union). Type guards can be built-in checks like typeof or instanceof, or custom user-defined type predicates (functions returning arg is Type). When the check passes, TypeScript 'narrows' the type for the scope of that block.

Code Example

function isString(test: any): test is string {
return typeof test === "string";
}

function example(foo: any) {
if (isString(foo)) {
console.log(foo.length); // TypeScript knows foo is a string here
}
}

What is Function Overloading?

Quick Answer

Providing multiple function signatures for the same function name.

Detailed Explanation

Function overloading allows you to define multiple ways to call a function (with different parameter types or counts). However, in TypeScript, you still only have one implementation which must be compatible with all overload signatures.

Code Example
function makeDate(timestamp: number): Date;
function makeDate(m: number, d: number, y: number): Date;
function makeDate(mOrTimestamp: number, d?: number, y?: number): Date {
    if (d !== undefined && y !== undefined) {
        return new Date(y, mOrTimestamp, d);
    }
    return new Date(mOrTimestamp);
}

What is Non-null Assertion Operator (!)?

Quick Answer

It is a postfix expression operator that tells the compiler to ignore null and undefined types for the preceding expression.

Detailed Explanation

Sometimes you know better than the compiler that a value is not null (e.g., after a specific DOM lookup). By appending !, you assert that the value is non-null. However, this is unsafe if you are wrong, as it leads to runtime errors. Use with caution.

Code Example

const element = document.getElementById("app")!;
// Compiler treats element as HTMLElement, not HTMLElement | null

Detailed Explanation

never is a bottom type in TypeScript. It is used in advanced type manipulation and exhaustive checking. If you have a union type and you handle directly all possible cases in a switch statement, the default case can be assigned to never to ensure that no new cases are missed in the future.

What is the difference between Pick<T, K> and Omit<T, K>?

Quick Answer

Pick constructs a type by choosing a set of properties K from T, while Omit constructs a type by removing a set of properties K from T.

Detailed Explanation

Both are transformation utilites. Pick is inclusive: you list what you want to keep. Omit is exclusive: you list what you want to remove. They are often used to create specialized versions of larger interfaces.

Code Example

interface Todo {
title: string;
description: string;
completed: boolean;
}

type TodoPreview = Pick<Todo, "title" | "completed">;
type TodoInfo = Omit<Todo, "completed">;

What is the Nullish Coalescing Operator ???

Quick Answer

It returns the right-hand side operand when the left-hand side is null or undefined.

Detailed Explanation

Unlike the || operator, which falls back for any falsy value (like 0 or ""), ?? only falls back for null or undefined. This is useful for preserving valid 0 or empty string values.

Code Example
const input = 0;
const result = input ?? 10; // result is 0
const result2 = input || 10; // result2 is 10
