Can interfaces be extended?

Click to reveal  ·  Space
Quick Answer

Yes, using the extends keyword.

Explanation

An interface can extend one or more other interfaces, copying their members into itself. This promotes reusability.

Code Example
interface Shape { color: string; }
interface Square extends Shape { side: number; }
