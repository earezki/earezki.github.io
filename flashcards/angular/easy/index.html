@Input and @Output?

Quick Answer

Data flow between components.

Detailed Explanation
  • @Input: Parent passes data to Child.
  • @Output: Child emits events to Parent (via EventEmitter).
Code Example
@Input() hero: Hero;
directives

ngIf vs hidden?

Quick Answer

ngIf removes the element from DOM; hidden just hides it with CSS.

Detailed Explanation

Use ngIf when the element shouldn't exist (better for performance if expensive to create). Use hidden if you toggle visibility frequently.

Code Example
<div *ngIf="show">Exists?</div>

Data BindingBasics

Explain Two-Way Data Binding.

Quick Answer

A mechanism to sync data between the component (TypeScript) and the view (HTML) in both directions.

Detailed Explanation

Changes in the model update the view, and usage input in the view updates the model. In Angular, this uses the [(ngModel)] syntax (Banana-in-a-box).

Code Example

<input [(ngModel)]="name">

FormsBasics

Template-Driven vs Reactive Forms?

Quick Answer

Template-Driven relies on directives (ngModel) in the HTML. Reactive Forms relies on creating a model tree (FormGroup, FormControl) in code.

Detailed Explanation

Template-driven is simpler for small forms. Reactive is more powerful, scalable, testable, and robust for complex forms with dynamic validation.

What is a Component in Angular?

Quick Answer

The main building block of an Angular application.

Detailed Explanation

A component controls a patch of screen called a view. It consists of a TypeScript class (logic), an HTML template (view), and CSS styles. The @Component decorator identifies the class as a component.

    templateUrl: './home.component.html'
})
