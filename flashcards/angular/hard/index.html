APP_INITIALIZER?

Click to reveal  ·  Space
Quick Answer

Token to run code during app startup.

Explanation

Allows delaying app initialization until a Promise resolves (e.g., loading config from server).

Code Example
{ provide: APP_INITIALIZER, useFactory: ..., multi: true }
