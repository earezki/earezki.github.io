@HostBinding?

Quick Answer

Binds a property to the host element.

Detailed Explanation

Change a property (like class, style, id) of the host element based on directive/component state.

Code Example

@HostListener?

Quick Answer

Listens to events on the host element.

Detailed Explanation

Used in directives to react to events on the element the directive is attached to.

Code Example
@HostListener('click') onClick() { ... }

Quick Answer

Data down vs Events up.

Detailed Explanation
  • @Input: Receives data from parent.
  • @Output: Emits events to parent.
Code Example
@Input() hero: Hero;
@Output() delete = new EventEmitter();

RxJSAsync

AsyncPipe usage?

Quick Answer

It subscribes to an Observable (or Promise) in the template and returns the latest emitted value.

Detailed Explanation

Crucially, it also automatically unsubscribes when the component is destroyed, preventing memory leaks. It avoids the need to manually store subscriptions in the component class.

Code Example
{{ users.length }}
DOMDirectives

ElementRef and Renderer2?

Quick Answer

ElementRef gives direct access to the DOM element (risky). Renderer2 is a safe API to manipulate the DOM.

Detailed Explanation

Direct DOM access breaks Angular's abstraction (Web Workers, Server-Side Rendering). Renderer2 works across all platforms. renderer.setStyle(el.nativeElement, 'color', 'red').

Quick Answer

HostListener listens to events on the host element. HostBinding binds a property to a property of the host element.

Detailed Explanation

Used in Directives. HostListener('click') runs code when element is clicked. HostBinding('class.active') adds a class class conditionally.

Code Example

@HostBinding('style.color') color = 'blue';

OptimizationChange Detection

OnPush Change Detection Strategy?

Quick Answer

A strategy where Angular only checks the component when its Input references change or an event originates from the component.

Detailed Explanation

By default (Default), Angular checks every component on every async event. OnPush improves performance significantly by skipping subtrees that haven't changed. You might need ChangeDetectorRef.markForCheck() manually sometimes.

Code Example

changeDetection: ChangeDetectionStrategy.OnPush

Difference between Promise vs Observable?

Quick Answer

Promises are single-value and eager; Observables are multi-value (stream) and lazy.

Detailed Explanation

Observables are cancellable (using unsubscribe) and support powerful operators (map, filter, retry). Promises cannot be cancelled easily.

Code Example
Observable: Can emit multiple times over time.

dependency-injection

How does Dependency Injection work in Angular?

Quick Answer

It provides dependencies to a class rather than the class creating them itself.

Detailed Explanation

Angular has a hierarchical injection system. You register a provider (usually in a module or component), and when a component requests a dependency (in its constructor), the injector provides a singleton instance (relative to the injector scope).

Code Example

How to handle HTTP errors?

Quick Answer

Use the catchError operator from RxJS.

Detailed Explanation

In the pipe chain of the Observable returned by HttpClient, catchError lets you handle the error (e.g., log it) and return a fallback value or rethrow.

Code Example

  catchError(this.handleError)
);

How to lazy load a module?

Quick Answer

Using the loadChildren property in the routing configuration.

Detailed Explanation

Angular bundles the module into a separate JS file chunk. It is only downloaded from the server when the user navigates to that route for the first time, speeding up initial load time.

Code Example

{ path: 'admin', loadChildren: () => import('./admin/admin.module')... }

rxjs

Subject vs BehaviorSubject?

Quick Answer

BehaviorSubject holds an initial value and emits it to new subscribers.

Detailed Explanation
  • Subject: Does not hold a value. Subscribers only receive events emitted after they subscribe.
  • BehaviorSubject: Holds the latest value. Subscribers receive the last value immediately upon subscription.
Code Example
const bs = new BehaviorSubject(0);
bs.subscribe(val => console.log(val)); // logs 0 immediately
RxJSCommon

Subject vs BehaviorSubject?

Quick Answer

Subject doesn't have an initial value; subscribers only get values emitted after they subscribe. BehaviorSubject has an initial value and replays the last value to new subscribers.

Detailed Explanation

Use BehaviorSubject for state services (like 'CurrentUser') so new components get the current data immediately upon loading.

Code Example

const bs = new BehaviorSubject(0);

rxjs

Subject vs Observable?

Quick Answer

Subject is multicast.

Detailed Explanation

Observable is usually unicast (one execution per subscriber). Subject shares execution (like an Event Emitter) and acts as both observer and observable.

Code Example
subject.next('val');

What is a Pure Pipe?

Quick Answer

A pipe that is executed only when a pure change to the input value is detected.

Detailed Explanation

A pure change is either a change to a primitive value or a change to the object reference. This makes pure pipes performant. Impure pipes run on every change detection cycle.
