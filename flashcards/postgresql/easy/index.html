commands

\d command?

Quick Answer

Describe table.

Detailed Explanation

In psql (interactive terminal), \d tablename shows the table structure (columns, types, constraints). \dt lists tables.

Code Example
\d users
TransactionsACID

BEGIN, COMMIT, ROLLBACK?

Quick Answer

Transaction controls.

Detailed Explanation

BEGIN starts a transaction. COMMIT saves changes. ROLLBACK undoes changes since BEGIN.

Code Example

BEGIN; UPDATE acc SET bal=bal-10; UPDATE acc2 SET bal=bal+10; COMMIT;

CHECK constraint?

AggregatesGrouping

GROUP BY and HAVING?

Quick Answer

GROUP BY groups rows that have the same values into summary rows. HAVING filters groups.

Detailed Explanation

WHERE filters rows before grouping. HAVING filters groups after aggregation.

Code Example

SELECT dept, COUNT() FROM emp GROUP BY dept HAVING COUNT() > 5;

JoinsBasics

INNER JOIN vs LEFT JOIN?

Quick Answer

Inner Join returns rows when there is a match in both tables. Left Join returns all rows from left table, and matched rows from right.

Detailed Explanation

If no match in right table, Left Join returns NULLs for right columns.

Code Example

SELECT * FROM users u LEFT JOIN orders o ON u.id = o.user_id;

FilteringPattern

LIKE vs ILIKE?

Quick Answer

LIKE is case-sensitive. ILIKE is case-insensitive.

Detailed Explanation

% matches any sequence of characters. _ matches single character. ILIKE is specific to PostgreSQL.

Code Example

SELECT * FROM users WHERE name ILIKE 'john%';

json

JSON Support in Postgres?

Quick Answer

Native JSON data types.

Detailed Explanation

PostgreSQL offers two types for storing JSON data: json (text storage) and jsonb (binary storage, faster processing and indexing).

Code Example
SELECT * FROM docs WHERE data->>'key' = 'value';
Data TypesJSON

JSONB in PostgreSQL?

Quick Answer

A binary format for storing JSON data.

Detailed Explanation

Unlike JSON (text), JSONB is decomposed and indexed, making it much faster to query/filter specific keys.

Code Example

SELECT * FROM docs WHERE data->>'status' = 'active';

ConstraintsKeys

Primary Key vs Unique Key?

Quick Answer

Primary Key uniquely identifies a row and cannot be NULL. Unique Key ensures uniqueness but can allow one NULL (depending on DB).

Detailed Explanation

A table can have only one Primary Key but multiple Unique Keys.

Code Example

CREATE TABLE users (id SERIAL PRIMARY KEY, email VARCHAR UNIQUE);
