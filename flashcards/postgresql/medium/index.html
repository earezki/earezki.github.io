ConcurrencyLocking

SELECT ... FOR UPDATE?

Quick Answer

Locks the selected rows for writing within the transaction.

Detailed Explanation

Prevents other transactions from modifying or locking these rows until the current transaction ends. Prevents race conditions.

Code Example

BEGIN; SELECT * FROM stock WHERE id=1 FOR UPDATE; ... COMMIT;

Full Text SearchSearch

tsvector and tsquery?

Quick Answer

PostgreSQL built-in Full Text Search data types.

Detailed Explanation

tsvector stores sorted list of lexemes (normalized words). tsquery represents the search query (boolean operators).

Code Example

SELECT * FROM docs WHERE to_tsvector(body) @@ to_tsquery('postgres & fast');

IndexPerformance

B-Tree Index vs Hash Index?

Quick Answer

B-Tree is default and handles equality (=) and range (<, >, BETWEEN). Hash Index only handles equality.

Detailed Explanation

B-Tree is sorted. Hash index is O(1) but not crash-safe in older Postgres versions (safe since v10).

Code Example

CREATE INDEX idx_name ON users USING btree (name);

indexes

B-Tree Index?

Quick Answer

Default index.

Detailed Explanation

Code Example
CREATE INDEX idx_name ON table(col);

ReplicationViews

Materialized View vs View?

Quick Answer

Standard View is a saved query (runs every time). Materialized View saves the result physically on disk.

Detailed Explanation

Materialized views are much faster for heavy aggregates but data is stale. Must be refreshed explicitly using REFRESH MATERIALIZED VIEW.

views

Materialized Viewed?

Quick Answer

Physically stored view.

Detailed Explanation

A rule-based view where the results are physically stored in a table-like object. Must be refreshed manually (REFRESH MATERIALIZED VIEW).

AdvancedCTE

Recursive CTE (Common Table Expression)?

Quick Answer

Allows query to reference itself. Useful for hierarchical data (Trees, Org Charts).

Detailed Explanation

Structure: 1. Anchor member (base case). 2. Recursive member (joins with CTE). 3. Termination condition.

Code Example

WITH RECURSIVE subordinates AS (...) SELECT * FROM subordinates;

What is RETURNING clause?

Quick Answer

Return modified rows.

Detailed Explanation

Clause used in INSERT, UPDATE, DELETE to return the values of the rows that were modified by the command. Avoids extra SELECT.

OptimizationVacuum

What is VACUUM?

Quick Answer

Reclaims storage occupied by dead tuples.

Detailed Explanation

Postgres uses MVCC (Multi-Version Concurrency Control). Updates/Deletes mark old rows as 'dead' but don't remove them. Vacuum clears them. VACUUM FULL locks table and rewrites it.

indexes

What is a Partial Index?

Quick Answer

Index on subset of rows.

Detailed Explanation

An index built over a subset of rows in a table defined by a conditional expression (WHERE clause). Reduces index size and maintenance costs.

Code Example
CREATE INDEX idx_active ON users (email) WHERE active = true;

What is PostGIS?

Quick Answer

Geographic objects support.

Detailed Explanation

Spatial database extender for PostgreSQL. It adds support for geographic objects allowing location queries to be run in SQL.

Code Example

FunctionsWindow

Window Functions (ROW_NUMBER, RANK)?

Quick Answer

Perform calculations across a set of table rows that are related to the current row.

Detailed Explanation

Unlike GROUP BY, rows retain their separate identities. PARTITION BY defines the group scope.

Code Example

SELECT name, salary, RANK() OVER (ORDER BY salary DESC) FROM emp;
