InternalsMVCC

How Postgres implements MVCC?

Quick Answer

Multi-Version Concurrency Control using xmin and xmax system columns.

Detailed Explanation

Every row has transaction IDs for creation (xmin) and deletion (xmax). A transaction only sees rows where xmin committed before it started and xmax is null or invalid. Readers don't block writers.

Code Example

SELECT xmin, xmax, * FROM table;

Detailed Explanation
