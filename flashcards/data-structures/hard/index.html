B-Tree vs B+ Tree?

Quick Answer

B-Tree stores keys and data in internal nodes. B+ Tree stores keys in internal nodes and keys+data only in leaf nodes.

Detailed Explanation

B+ Tree leaves are linked, making range queries efficient. This makes B+ Trees ideal for database indexing and file systems.

Bloom Filter?

Quick Answer

A space-efficient probabilistic data structure that tests whether an element is a member of a set.

Detailed Explanation

It can tell you if an element is possibly in the set or definitely not in the set. False positives are possible; false negatives are not. Used in databases to avoid expensive disk lookups for non-existent keys.

Consistent Hashing?

Quick Answer

A hashing technique where resizing the hash table (adding/removing slots) only requires remapping $K/n$ keys on average.

Detailed Explanation

Used in distributed caching (like DynamoDB, Cassandra). Nodes are placed on a ring. Keys are mapped to the next node on the ring clockwise.

AdvancedSet

Disjoint Set Union (DSU) / Union-Find?

Quick Answer

A data structure that keeps track of a set of elements partitioned into a number of disjoint (non-overlapping) subsets.

Detailed Explanation

Supports union(a, b) (merge sets) and find(a) (find representative) in nearly $O(1)$ time (Ackermann inverse) using Path Compression and Union by Rank. Used in Kruskal's algorithm.

ProbabilisticBig Data

HyperLogLog?

Quick Answer

A probabilistic algorithm for the count-distinct problem (counting unique elements in a large dataset).

Detailed Explanation

It uses extremely little memory (e.g. 1.5kb) to count billions of unique items with typically <2% error. Used by Redis (PFCOUNT).

KMP Algorithm (Knuth-Morris-Pratt)?

Quick Answer

A string searching algorithm that searches for occurrences of a 'word' within a main 'text' in $O(n+m)$ time.

Detailed Explanation

It pre-processes the pattern to create an LPS (Longest Prefix Suffix) array, allowing it to skip character comparisons after a partial match fails, avoiding backtracking.

Segment Tree vs Fenwick Tree (Binary Indexed Tree)?

Quick Answer

Both perform range queries and point updates in $O(\log n)$.

Detailed Explanation

Fenwick Tree is simpler to code and uses less memory but handles fewer operations (usually prefix sums). Segment Tree is more flexible (min/max range queries) but uses $4n$ space.

Skip List?

Quick Answer

A probabilistic data structure that allows $O(\log n)$ search/insert/delete within an ordered sequence.

Detailed Explanation

It consists of layers of linked lists. Bottom layer is a normal list. Higher layers act as 'express lanes' skipping over multiple elements. Easier to implement/lock than balanced trees.

TreesString

Suffix Tree?

Quick Answer

A compressed trie of all suffixes of a given text.

Detailed Explanation

Allows fast implementation of many string operations generally in $O(n)$ time: finding a substring, longest common substring, etc. Complex to build (Ukkonen's algorithm).

What is a Red-Black Tree?

Quick Answer

A self-balancing binary search tree where each node has an extra bit for color (red or black).

Detailed Explanation

It ensures the path from the root to the farthest leaf is no more than twice as long as the path to the nearest leaf. Used in Java's TreeMap and C++ std::map.
