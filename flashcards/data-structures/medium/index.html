GraphMatrices

Adjacency Matrix vs Adjacency List?

Quick Answer

Matrix is a 2D array ($V \times V$). List is an array of lists.

Detailed Explanation

Matrix takes $O(V^2)$ space; fast to check if edge exists ($O(1)$). List takes $O(V+E)$ space; usually better for sparse graphs (most real-world graphs).

TreesBalanced

AVL Tree?

Quick Answer

A self-balancing Binary Search Tree.

Detailed Explanation

It maintains the property that the heights of the two child subtrees of any node differ by at most one. If at any time they differ by more than one, rebalancing (rotation) is performed to restore this property.

GraphTraversal

BFS vs DFS?

Quick Answer

BFS (Breadth-First Search) explores neighbors first (Queue). DFS (Depth-First Search) explores as deep as possible first (Stack/Recursion).

Detailed Explanation

BFS finds the shortest path in unweighted graphs. DFS is better for pathfinding puzzles (mazes), topological sorting, or cycle detection.

HeapUsage

Finding K-th Largest Element?

Quick Answer

Use a Min-Heap of size K.

Detailed Explanation

Iterate through the array. Add element to heap. If heap size > K, remove the smallest (root). At the end, the heap root is the K-th largest element. Complexity $O(n \log k)$.

LinkedListCycle

Floyd's Tortoise and Hare Algorithm?

Quick Answer

A pointer algorithm that uses two pointers moving at different speeds to detect a cycle in a sequence of values.

Detailed Explanation

Fast pointer moves 2 steps, slow pointer moves 1 step. If they meet, there is a cycle. Used for Linked List cycle detection.

HashingCollisions

Hash Collision Resolution Strategies?

Quick Answer

Chaining (Linked Lists) and Open Addressing (Probing).

Detailed Explanation

Chaining: Each bucket holds a list of entries. Open Addressing: If bucket is full, find another spot (Linear Probing, Quadratic Probing). Java's HashMap uses Chaining (and converts to Red-Black Tree if chain is long).

StackQueue

Implement Queue using Stacks.

Quick Answer

Use two stacks: input and output.

Detailed Explanation

Push to input. To pop/peek, check output. If empty, pop all from input and push to output. This reverses the order ($LIFO \to FIFO$). Amortized complexity is $O(1)$.

TreesTraversal

In-order, Pre-order, Post-order Traversal?

Quick Answer

DFS traversal orders. Pre: Root-Left-Right. In: Left-Root-Right. Post: Left-Right-Root.

Detailed Explanation

In-order traversal of a BST yields sorted values. Post-order is useful for deleting trees (delete children before parent). Pre-order is useful for copying trees.

TreesBST

What is a Binary Search Tree (BST)?

Quick Answer

A binary tree where the left child is smaller than the parent, and the right child is greater.

Detailed Explanation

This property allows for efficient searching, insertion, and deletion ($O(\log n)$ on average). In the worst case (unbalanced, like a linked list), it degrades to $O(n)$.

TrieStrings

What is a Trie (Prefix Tree)?

Quick Answer

A tree-like data structure used for storing strings efficiently.

Detailed Explanation

Each node represents a character. Useful for autocomplete or spell checking. Finding a word of length $L$ takes $O(L)$ time, independent of the number of words in the dictionary.
