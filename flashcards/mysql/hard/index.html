Quick Answer

Transaction Isolation Levels?

Quick Answer

It defines visibility of changes between transactions.

Detailed Explanation

MySQL supports 4 levels:

  1. READ UNCOMMITTED (Dirty Reads possible)
  2. READ COMMITTED (No Dirty Reads)
  3. REPEATABLE READ (Default in InnoDB, prevents Non-Repeatable Reads)
  4. SERIALIZABLE (Highest, prevents Phantom Reads).
Code Example
SET TRANSACTION ISOLATION LEVEL READ COMMITTED;

What are Window Functions?

Quick Answer

Calculations across a set of table rows.

Detailed Explanation

Perform a calculation across a set of table rows that are somehow related to the current row. Unlike aggregate functions, they do not cause rows to become grouped into a single output row.
