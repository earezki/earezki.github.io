data-types

CHAR vs VARCHAR?

Quick Answer

Fixed length vs Variable length strings.

Detailed Explanation
  • CHAR: Fixed length. Padded with spaces to specified length.
  • VARCHAR: Variable length. Stores only the characters plus a 1- or 2-byte length prefix.

joins

UNION vs UNION ALL?

Quick Answer

UNION removes duplicates, UNION ALL keeps them.

Detailed Explanation
  • UNION: Combines the result-set of two or more SELECT statements and removes duplicate rows.
  • UNION ALL: Combines result-sets but allows duplicate rows (faster as it skips distinct check).
Code Example
SELECT City FROM Customers UNION SELECT City FROM Suppliers;

What is COALESCE()?

Quick Answer

It returns the first non-null value in a list.

Detailed Explanation

The COALESCE() function evaluates the arguments in order and returns the current value of the first expression that initially does not evaluate to NULL.

Code Example
SELECT COALESCE(NULL, NULL, 'W3Schools.com', NULL, 'Example.com');
aggregation

What is GROUP BY used for?

Quick Answer

It groups rows that have the same values into summary rows.

Detailed Explanation

The GROUP BY statement groups rows that have the same values into summary rows, usually used with aggregate functions (COUNT, MAX, MIN, SUM, AVG).

Code Example
SELECT COUNT(CustomerID), Country FROM Customers GROUP BY Country;
joins

What is a LEFT JOIN?

Quick Answer

It returns all records from the left table, and matched records from the right.

Detailed Explanation

The LEFT JOIN keyword returns all records from the left table (table1), and the matched records from the right table (table2). The result is NULL from the right side, if there is no match.

Code Example
SELECT * FROM Customers LEFT JOIN Orders ON Customers.ID=Orders.CustomerID;
constraints

What is a UNIQUE constraint?

Quick Answer

It ensures that all values in a column are distinct.

Detailed Explanation

The UNIQUE constraint ensures that all values in a column are different. Both the UNIQUE and PRIMARY KEY constraints provide a guarantee for uniqueness for a column or set of columns.

Code Example
CREATE TABLE P (ID int UNIQUE);
transactions

What is a Transaction?

Quick Answer

A sequence of operations performed as a single logical unit of work.

Detailed Explanation

A transaction is a logical unit of work that contains one or more SQL statements to interact with the database. Transactions must follow ACID properties (Atomicity, Consistency, Isolation, Durability).

Code Example
START TRANSACTION;
INSERT ...;
COMMIT;
views

What is a View?

Quick Answer

A virtual table based on the result-set of an SQL statement.

Detailed Explanation

A view is a virtual table sitting on top of SQL queries. It contains rows and columns, just like a real table. The fields in a view are fields from one or more real tables in the database.

Code Example
CREATE VIEW PortugalCustomers AS SELECT * FROM Customers WHERE Country='Portugal';
indexes

What is an Index?

Quick Answer

Data structure to speed up data retrieval.

Detailed Explanation

Indexes are used to find values within a specific column more quickly. Without an index, MySQL has to scan the whole table to find the relevant rows.

Code Example
CREATE INDEX idx_lastname ON Customers (LastName);
aggregation

What is the HAVING clause?

Quick Answer

It filters groups created by GROUP BY.

Detailed Explanation

The HAVING clause was added to SQL because the WHERE keyword could not be used with aggregate functions. It applies conditions to the grouped records.

Code Example
SELECT Count(ID), Country FROM Customers GROUP BY Country HAVING Count(ID) > 5;
