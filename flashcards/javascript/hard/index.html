Object.freeze() vs Object.seal()?

Quick Answer

freeze() makes an object immutable (cannot add, delete, or change properties). seal() prevents adding/deleting, but allows modifying existing values.

Detailed Explanation

Both are shallow. Nested objects are not frozen/sealed unless you recursively apply the method. Use these for improving security or preventing accidental state mutation.

Event Loop and Microtasks?

Quick Answer

Task queue priority.

Detailed Explanation

The Event Loop processes the Microtask Queue (Promises, MutationObserver) completely before moving to the next Macrotask (setTimeout, I/O).

Code Example

Explain 'Generator Functions' and 'Yield'.

Quick Answer

Generators (function*) can be paused and resumed. yield returns a value and pauses execution. item.next() resumes it.

Detailed Explanation

They allow writing iterators easily and controlling asynchronous flow (like co library used to do). They are the underlying mechanism for Redux-Saga.

Code Example

function* idGen() {
let i = 0;
while(true) yield i++;
}

Explain the difference between Microtasks and Macrotasks.

Quick Answer

Microtasks (Promises, MutationObserver) have higher priority and run immediately after the current script. Macrotasks (setTimeout, I/O) run in the next loop iteration.

Detailed Explanation

The Event Loop empties the entire microtask queue before moving to the next macrotask. This means infinite recursive microtasks (Promise loops) can block the UI, while recursive setTimeouts won't.

Explain the Temporal Dead Zone (TDZ).

Quick Answer

The period between the entering of a scope and the actual declaration of a let or const variable.

Detailed Explanation

Trying to access the variable in the TDZ throws a ReferenceError. This prevents the confusing 'undefined' behavior of var hoisting and enforces executing declaration before usage.

Code Example

{
// TDZ starts
console.log(x); // ReferenceError
let x = 3; // TDZ ends
}

How does Garbage Collection work in V8 (Generational)?

Quick Answer

V8 uses a generational approach: 'New Space' (scavenge algorithm for young objects) and 'Old Space' (Mark-Sweep-Compact for long-lived objects).

Detailed Explanation

Objects start in New Space. If they survive a GC cycle, they move to Old Space. This optimizes performance because most objects die young. 'Mark-Sweep' traverses roots to find reachable objects and frees the rest.

WeakMap vs Map?

Quick Answer

Garbage collection behavior.

Detailed Explanation
  • Map: Holds strong reference to keys.
  • WeakMap: Holds weak reference. Keys must be objects. If key has no other refs, it can be GC'd.
Code Example
wm.set(domNode, data);

WeakMap vs Map?

Quick Answer

WeakMap keys must be objects and are held weakly (eligible for GC if not used elsewhere). Map keeps strong references.

Detailed Explanation

WeakMap is not iterable and has no size property. It is perfect for associating private data with DOM elements or objects without causing memory leaks when the object is deleted.

Code Example

let obj = {};
const wm = new WeakMap();
wm.set(obj, "meta data");
obj = null; // entry in WeakMap is removed by GC

What is Currying?

Quick Answer

Function transformation.

Detailed Explanation

Transforming a function that takes multiple arguments f(a,b) into a sequence of functions that each take a single argument f(a)(b).

Code Example

What is Currying?

Quick Answer

Currying is the transformation of a function with multiple arguments f(a, b, c) into a sequence of nested functions f(a)(b)(c).

Detailed Explanation

It allows partial application. You can fix some arguments first and reuse the returned function. Useful in functional composition.

Code Example

const add = a => b => a + b;
const add5 = add(5);
add5(10); // 15

What is Tail Call Optimization (TCO)?

Quick Answer

An optimization where the engine does not create a new stack frame for the last function call in a function.

Detailed Explanation

It prevents Stack Overflow in recursive functions if written in tail-recursive style. While part of ES6 spec, support in major browsers (except Safari) is limited/dropped.

Code Example

function fact(n, acc=1) {
if (n <= 1) return acc;
return fact(n-1, n*acc); // Tail call
}

What is the Prototype Chain?

Quick Answer

It is JavaScript's mechanism for inheritance. Objects have a private property [[Prototype]] linking to another object.

Detailed Explanation

When access a property, JS checks the object. If missing, it checks the prototype, then the prototype's prototype, until null is reached. This chain allows objects to inherit properties and methods from other objects.

Code Example

obj.proto === Object.prototype; // usually true
