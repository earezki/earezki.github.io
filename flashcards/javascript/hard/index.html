0.1 + 0.2 !== 0.3?

Click to reveal  ·  Space
Quick Answer

Floating point precision.

Explanation

JS uses IEEE 754 doubles. Binary representation of 0.1 is infinite. Rounding errors occur.

Code Example
0.30000000000000004
