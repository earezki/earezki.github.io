bind, call, apply?

Quick Answer

Manually set this.

Detailed Explanation
  • call(thisObj, arg1): Invokes immediately.
  • apply(thisObj, [args]): Invokes immediately (array args).
  • bind(thisObj): Returns new function.
Code Example
fn.call(obj, 1, 2);
functions

call vs apply vs bind?

Quick Answer

Function borrowing.

Detailed Explanation
  • call: Invokes function with this and args list.
  • apply: Invokes function with this and args array.
  • bind: Returns a new function with this bound (does not invoke).
Code Example
func.call(obj, 1, 2)

call, apply, and bind?

Quick Answer

All three allow you to manually set the this context for a function.

Detailed Explanation

call invokes the function immediately with arguments listed. apply invokes immediately with arguments as an array. bind returns a new function with this permanently bound, to be called later.

Code Example

func.call(obj, 1, 2);
func.apply(obj, [1, 2]);
const boundFunc = func.bind(obj);

map vs forEach?

Quick Answer

forEach iterates over an array and executes a function (for side effects). map iterates and returns a new array with the results.

Detailed Explanation

Use map when you want to transform elements. Use forEach when you want to loop without returning anything. map is chainable; forEach is not.

Code Example

const doubles = [1,2].map(x => x*2); // [2,4]
[1,2].forEach(x => console.log(x));

Explain the this keyword.

Quick Answer

this refers to the object that is executing the current function.

Detailed Explanation

Its value depends on how the function is called. In a method, this is the object. In a standard function, this is global (or undefined in strict mode). In an event, it's the element. usage of call, apply, or bind can explicitly set this.

Code Example

const person = {
name: 'John',
greet() { console.log(this.name); }
};

What is a Closure in JavaScript?

Quick Answer

A closure is the combination of a function bundled together (enclosed) with references to its surrounding state (the lexical environment).

Detailed Explanation

In simpler terms, a closure gives you access to an outer function's scope from an inner function, even after the outer function has finished executing. This is used for data privacy and factories.

Code Example

function makeCounter() {
let count = 0;
return function() {
return count++;
};
}
const counter = makeCounter();
console.log(counter()); // 0

What is the Event Loop?

Quick Answer

The mechanism that allows JavaScript to perform non-blocking I/O operations despite being single-threaded.

Detailed Explanation

It constantly checks if the Call Stack is empty. If it is, and there are callback functions waiting in the Task Queue (from SetTimeout, APIs), it pushes them onto the stack to be executed.
