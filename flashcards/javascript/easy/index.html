== vs ===?

Click to reveal  ·  Space
Quick Answer

== checks for equality with type coercion (loose equality). === checks for equality without type coercion (strict equality).

Explanation

Always use === to avoid unexpected results. With ==, 1 == '1' is true. With ===, it is false because one is a number and the other is a string.

Code Example

0 == false // true
0 === false // false
