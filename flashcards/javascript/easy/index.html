== vs ===?

Quick Answer

== vs ===?

Quick Answer

Coercion vs Strict.

Detailed Explanation
  • ==: Abstract equality. Performs type conversion (coercion) before comparison.
  • ===: Strict equality. Checks both value and type.
Code Example
1 == '1' // true
1 === '1' // false

== vs ===?

Quick Answer

== checks for equality with type coercion (loose equality). === checks for equality without type coercion (strict equality).

Detailed Explanation

Always use === to avoid unexpected results. With ==, 1 == '1' is true. With ===, it is false because one is a number and the other is a string.

Code Example

0 == false // true
0 === false // false

What does 'hoisting' mean?

Quick Answer

Hoisting is JavaScript's default behavior of moving declarations to the top of the current scope (script or function).

Detailed Explanation

Variable declarations (var) and function declarations are hoisted. This means you can call a function before it is defined in the code. Initializations are NOT hoisted.

Code Example

sayHi(); // Works
function sayHi() { console.log("Hi"); }

What is NaN?

Quick Answer

Not a Number.

Detailed Explanation

Result of an invalid math operation (e.g. "abc" / 2). Type is actually 'number'.

Code Example
isNaN("hello"); // true

What is NaN?

Quick Answer

NaN stands for 'Not-a-Number'. It represents a value that is not a legal number.

Detailed Explanation

It results from undefined mathematical operations (like 0/0 or parseInt("hello")). Interestingly, typeof NaN is 'number', and it is the only value in JavaScript that is not equal to itself (NaN === NaN is false). Use Number.isNaN() to check for it.

Code Example

console.log(0/0); // NaN
console.log(NaN === NaN); // false

What is a Callback Function?

Quick Answer

A function passed as an argument to another function, to be executed later.

Detailed Explanation

Callbacks are the foundation of asynchronous programming in JS (before Promises). They allow code to run in response to an event (like a click or data arriving) without blocking the main thread.

Code Example

function greet(name) {
alert('Hello ' + name);
}
function input(callback) {
var name = prompt('Name?');
callback(name);
}

What is the difference between let, const, and var?

Quick Answer

var is function-scoped and hoisted. let and const are block-scoped. const cannot be reassigned (immutable reference).

Detailed Explanation

var variables can be accessed before declaration (undefined) due to hoisting. let and const are also hoisted but reside in the 'Temporal Dead Zone' until declared. Always prefer const by default, then let. Avoid var in modern JS.

Code Example

if (true) {
var a = 1;
let b = 2;
}
console.log(a); // 1
console.log(b); // ReferenceError

What is the difference between null and undefined?

Quick Answer

undefined means a variable has been declared but not assigned a value. null is an assignment value representing 'no value' or 'empty'.

Detailed Explanation

JavaScript assigns undefined automatically. null is assigned by programmers to indicate intention. undefined is a type itself; null is an object.

Code Example

let x;
console.log(x); // undefined
let y = null;
